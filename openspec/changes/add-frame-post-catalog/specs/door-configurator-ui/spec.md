## ADDED Requirements

### Requirement: Отображение позиций короба
Если выбранная конфигурация содержит frame-компонент, для которого каталог отдаёт непустой список его позиций frame_post, система ДОЛЖНА (SHALL) отобразить этот список внутри карточки компонента «Короб» — для каждой позиции название её post_type, quantity, length (если задана) и retail_price/dealer_price. Этот список — только для отображения: ни одна его позиция не выбирается пользователем и не входит в запрос расчёта стоимости.

#### Scenario: Короб с несколькими позициями показывает их все
- **WHEN** выбранная конфигурация содержит frame-компонент, чей список позиций frame_post из каталога содержит две записи
- **THEN** карточка «Короб» показывает обе позиции с их названием, количеством, длиной (если задана) и ценой

#### Scenario: Короб без позиций не показывает список
- **WHEN** выбранная конфигурация содержит frame-компонент, чей список позиций frame_post из каталога пуст
- **THEN** карточка «Короб» не показывает список позиций, как и раньше

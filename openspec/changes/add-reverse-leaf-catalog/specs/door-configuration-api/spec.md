## ADDED Requirements

### Requirement: Надбавка за реверс при расчёте стоимости полотна
Если frame_type выбранной конфигурации отмечен как реверсивный (is_reverse), система ДОЛЖНА (SHALL), найдя подходящую строку configuration_price для leaf-компонента обычным образом, прибавить к найденным retail_price и dealer_price этого компонента надбавку за реверс. Надбавка применяется только к цене leaf-компонента и не влияет на цену короба (в т. ч. на сумму frame_post) и остальных компонентов конфигурации.

#### Scenario: Цена полотна включает надбавку при реверсивном коробе
- **WHEN** отправляется запрос расчёта стоимости для конфигурации, чей frame_type — реверсивный, и для её leaf_type найдена подходящая строка configuration_price
- **THEN** стоимость leaf-компонента равна найденной цене с прибавленной надбавкой за реверс, а стоимость остальных компонентов конфигурации надбавка не затрагивает

#### Scenario: Надбавка не применяется при обычном коробе
- **WHEN** отправляется запрос расчёта стоимости для конфигурации, чей frame_type не отмечен как реверсивный (либо frame_type не выбран)
- **THEN** стоимость leaf-компонента равна найденной цене без каких-либо надбавок

#### Scenario: Полотно без цены при реверсивном коробе остаётся некалькулируемым
- **WHEN** отправляется запрос расчёта стоимости для конфигурации, чей frame_type — реверсивный, и для её leaf_type не найдено подходящей строки configuration_price
- **THEN** leaf-компонент считается некалькулируемым, как и при обычном коробе

## MODIFIED Requirements

### Requirement: Сервис «Эмаль лайт»
В левом меню приложения ДОЛЖЕН (SHALL) присутствовать пункт «Эмаль лайт» рядом с пунктом «Эмаль и шпон». Каждый сервис ДОЛЖЕН (SHALL) соответствовать одному прайс-листу: «Эмаль и шпон» — `PL-001`, «Эмаль лайт» — `PL-002`. Конфигуратор сервиса ДОЛЖЕН (SHALL) предлагать только конфигурации, у которых прайс-лист leaf-компонента совпадает с прайс-листом сервиса, а подпись «Прайс-лист: <название файла>» в шапке ДОЛЖНА (SHALL) показывать название прайс-листа текущего сервиса. Каталог конфигураций НЕ ДОЛЖЕН (SHALL NOT) перезагружаться при каждом переключении между сервисами.

#### Scenario: Сервис «Эмаль лайт» показывает только свои коллекции
- **WHEN** пользователь открывает сервис «Эмаль лайт»
- **THEN** в выборе доступны только коллекции MONO, QUADRO, VENEZIA и REFLEX, а в шапке отображается «Прайс-лист: hausdoors_emal_layt_tsfo_05_10_2026»

#### Scenario: Сервис «Эмаль и шпон» не показывает коллекции «Эмаль лайт»
- **WHEN** пользователь открывает сервис «Эмаль и шпон»
- **THEN** коллекции MONO, QUADRO, VENEZIA и REFLEX недоступны, в шапке отображается «Прайс-лист: hausdoors_emal_i_shpon_rf_07_09_2026»

#### Scenario: Переключение между сервисами не перезапрашивает каталог
- **WHEN** пользователь переключается из «Эмаль и шпон» в «Эмаль лайт» и обратно
- **THEN** каталог конфигураций не запрашивается с сервера повторно

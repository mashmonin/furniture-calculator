## Context

Прайс-лист `PL-002` («Эмаль Лайт») заведён changeset'ом `0116-emal-layt-service.yaml`, фурнитура — `0126-emal-layt-hardware.yaml`. Мотивация и состав изменений — в proposal. Применённые changeset'ы редактировать нельзя, поэтому изменение оформляется новым changeset'ом (следующий номер — `0127`). Миграции должны одинаково выполняться на PostgreSQL и H2 (профиль `desktop`), без процедурной логики.

## Goals / Non-Goals

**Goals:**
- Переименовать `PL-002` в `hausdoors_emal_layt_tsfo_05_10_2026`.
- Поднять розничную цену полотна MONO MN 01 (высота 2000, ширины 400/600/700/800) с 17 761 до 18 761.

**Non-Goals:**
- Изменение схемы БД, API и кода frontend.
- Пересчёт сохранённых заказов и корзин.

## Decisions

1. **Новый changeset `0127-emal-layt-price-update-05-10-2026.yaml`** с двумя changeSet'ами: `UPDATE price_list` по `code = 'PL-002'` и `UPDATE configuration_price`. Переносимый SQL, без вендорных функций.
2. **Адресация строк цены** — через подзапросы по кодам и значениям опций (`leaf_type.code = 'LT-046'`, `DT-001` со значениями 400/600/700/800, `DT-002` со значением 2000), а не по суррогатным id. В условие добавляется `retail_price = 17761`, чтобы изменение не затронуло строку, уже изменённую иначе. Ожидается ровно 4 обновлённые строки; в tasks проверяется тестом.
3. **Rollback** — обратные `UPDATE` (название и цена 18 761 → 17 761).
4. **Название прайс-листа** берётся только из `price_list.name`; frontend привязан к `PL-002` по коду (`frontend/src/services.ts`), поэтому код не меняется.
5. **Тесты** обновляются в существующих классах `EmalLaytCatalogIntegrationTest` и `EmalLaytHardwareCatalogIntegrationTest`: новая цена, новое название. Запускаются только эти классы через `--tests` (полный `gradlew test` слишком долгий).

## Assumptions

- Дилерская цена 10 764 не меняется (по черновику).
- Остальные цены полотна и фурнитура в новом файле прайса совпадают с текущими — полный файл прайса не сверялся, источник — сравнение, приведённое в proposal.
- Цена высот 2100–2300 и ширины 900 для MONO MN 01 не менялась.
- Дата в имени файла `05_10_2026` — 5 октября 2026; имя берётся буквально из файла.
- Заказы/корзины хранят цену на момент создания и не пересчитываются.

## Risks / Trade-offs

- Если в БД строки цены MONO MN 01 уже изменены вручную, условие `retail_price = 17761` не сработает и обновление пропустит строки → проверка числа обновлённых строк в интеграционном тесте.
- Пользователи с открытой вкладкой увидят старое название до перезагрузки каталога — приемлемо.

## Context

Прайс-лист `PL-002` и цены полотен «Эмаль Лайт» заведены changeset'ом `0116-emal-layt-service.yaml` (`0116-1` — название, `0116-7` — 120 цен `configuration_price`). Уже применённые changeset'ы редактировать нельзя, поэтому правки выполняются новым changeset'ом. Последний changeset — `0126-emal-layt-hardware.yaml`. БД должна одинаково работать на PostgreSQL и H2 (desktop), без процедурной логики.

## Goals / Non-Goals

**Goals:**
- Переименовать `PL-002` и обновить 4 цены MONO MN 01 (ширины 400/600/700/800 × высота 2000).

**Non-Goals:**
- Изменения схемы, API, frontend; изменение других цен, моделей и фурнитуры.

## Decisions

- **Один новый changeset `0127-emal-layt-price-list-update-06-10-2026.yaml`** с двумя changeSet'ами: `0127-1` — `UPDATE price_list SET name = ... WHERE code = 'PL-002'`; `0127-2` — `UPDATE configuration_price` для `LT-046`, опций длины 400/600/700/800 и высоты 2000. Подключить в master после `0126`. Переносимый SQL, подзапросы по `leaf_type.code` и `liner_dimension_option` (как в `0116-7`), без привязки к id.
- **Rollback**: обратные `UPDATE` (имя `..._07_09_2026`; цены 17761 / 10764).
- **Фурнитура и коллекции** ссылаются на `PL-002` через FK, а не через строку названия — отдельных правок данных не требуется.
- **Delta-specs**: `MODIFIED` для требований «Цены полотна «Эмаль лайт» по размерам» (`door-configuration-catalog`) и «Прайс-лист «Эмаль лайт»» (`price-list-catalog`). Упоминания старого названия `..._07_09_2026` в других спеках (`hardware-catalog`, `door-configurator-ui`) — иллюстративные формулировки; их не трогаем, чтобы не расширять change.

## Допущения и риски

- **Цена 1 000 000 руб. выглядит аномально** (примерно в 50–100 раз выше соседних цен 11–20 тыс.) и может быть опечаткой или заглушкой. По указанию пользователя цены в черновике считаются точными, поэтому значение принимается как есть; перед выпуском рекомендуется сверить его с исходным файлом прайса.
- Обновляются только размеры, перечисленные в черновике; ширина 900 и высоты 2100–2300 остаются прежними.
- Тесты с ожиданиями 17761/10764 для MONO MN 01 (ширина 700, высота 2000) обновляются на новые значения.
- Нужно проверить при реализации, что тип столбцов `retail_price`/`dealer_price` вмещает 1000000.

## Migration Plan

Применение при старте приложения через Liquibase. Откат — rollback changeset'ов. Влияние на сохранённые заказы/корзину проверить при реализации (зависит от того, хранится ли цена снапшотом).

## MODIFIED Requirements

### Requirement: Расчёт стоимости по текущему выбору
Система ДОЛЖНА (SHALL) предоставлять действие «Рассчитать стоимость», доступное только когда выбрана конфигурация. При активации действия система ДОЛЖНА (SHALL) отправить id выбранной конфигурации и текущий выбор опций по каждому её компоненту (компоненты и оси без выбранного значения передаются как не выбранные) и отобразить результат: итоговую розничную и дилерскую цену и разбивку по компонентам — с найденной ценой компонента либо отметкой, что цена не найдена. После получения ответа (успешного результата либо сообщения об ошибке расчёта) система ДОЛЖНА (SHALL) автоматически прокрутить страницу так, чтобы соответствующий блок (результат расчёта либо сообщение об ошибке) стал видимым — так пользователь замечает, что расчёт произошёл, даже если до этого он находился в другом месте длинной страницы.

#### Scenario: Расчёт недоступен без выбранной конфигурации
- **WHEN** ни одна конфигурация не выбрана
- **THEN** действие «Рассчитать стоимость» недоступно для активации

#### Scenario: Расчёт без выбранных опций
- **WHEN** конфигурация выбрана, но ни одна опция размеров или цвета не выбрана, и активируется расчёт стоимости
- **THEN** запрос расчёта отправляется с id конфигурации без выбранных опций компонентов

#### Scenario: Успешный расчёт по всем компонентам
- **WHEN** backend возвращает результат расчёта, в котором цена найдена для всех компонентов конфигурации
- **THEN** страница показывает итоговую розничную и дилерскую цену и разбивку с ценой для каждого компонента

#### Scenario: Частичный расчёт
- **WHEN** backend возвращает результат расчёта, в котором для одного или нескольких компонентов цена не найдена
- **THEN** страница показывает итоговую цену, возвращённую backend, и отмечает в разбивке компоненты, для которых цена не найдена, не пересчитывая итог самостоятельно

#### Scenario: Ошибка расчёта
- **WHEN** запрос расчёта стоимости завершается ошибкой (сетевой сбой или ответ с кодом ошибки, включая 404 и 400)
- **THEN** страница показывает сообщение об ошибке расчёта и сохраняет текущий выбор конфигурации и опций без изменений

#### Scenario: Повторный расчёт после изменения выбора
- **WHEN** после отображения результата расчёта пользователь меняет выбор опции и повторно активирует расчёт стоимости
- **THEN** ранее показанный результат заменяется новым результатом расчёта по актуальному выбору

#### Scenario: Автопрокрутка к успешному результату
- **WHEN** активирован расчёт стоимости, и backend возвращает результат (полный или частичный)
- **THEN** страница автоматически прокручивается так, чтобы блок результата (итоговые цены и разбивка) стал видимым

#### Scenario: Автопрокрутка к сообщению об ошибке
- **WHEN** активирован расчёт стоимости, и запрос завершается ошибкой
- **THEN** страница автоматически прокручивается так, чтобы сообщение об ошибке стало видимым

#### Scenario: Повторный расчёт снова прокручивает к результату
- **WHEN** пользователь повторно активирует расчёт стоимости после изменения выбора (см. «Повторный расчёт после изменения выбора»)
- **THEN** страница снова автоматически прокручивается к новому результату, даже если пользователь успел прокрутить страницу в другое место после предыдущего расчёта

## ADDED Requirements

### Requirement: Сборка дистрибутива Windows
По запросу CI SHALL собрать дистрибутив под Windows (x86_64) на нативном Windows-раннере, используя тот же принцип полностью автономной упаковки (встроенный JRE), что и сборки под macOS (см. `desktop-app-packaging`). Сборка Windows SHALL выполняться в рамках того же запуска CI, что и обе сборки macOS.

#### Scenario: Запуск собирает три дистрибутива
- **WHEN** пользователь запускает сборку релиза
- **THEN** в рамках этого запуска собираются три дистрибутива — под arm64 (macOS), под x86_64 (macOS) и под Windows — независимо друг от друга

## MODIFIED Requirements

### Requirement: Публикация только после успеха обеих сборок
CI SHALL публиковать релиз только если сборки под все целевые платформы — обе архитектуры macOS и Windows — завершились успешно. Если сборка хотя бы одной из них завершилась с ошибкой, CI не SHALL публиковать релиз вовсе — не SHALL публиковать дистрибутивы только части платформ вместо всех.

#### Scenario: Одна из сборок падает
- **WHEN** сборка под x86_64 завершается ошибкой, а сборка под arm64 — успешно
- **THEN** релиз не публикуется — ни x86_64-, ни arm64-дистрибутив не появляются в списке доступных для скачивания

#### Scenario: Обе сборки успешны
- **WHEN** сборки под все целевые платформы — обе архитектуры macOS и Windows — завершаются успешно
- **THEN** релиз публикуется со всеми тремя дистрибутивами, доступными для скачивания

#### Scenario: Сборка Windows падает
- **WHEN** обе сборки macOS завершаются успешно, а сборка Windows — ошибкой
- **THEN** релиз не публикуется — ни один из трёх дистрибутивов не появляется в списке доступных для скачивания

### Requirement: Публикация в GitHub Releases с обоими дистрибутивами
Успешный релиз SHALL публиковаться как GitHub Release с тегом вида `v<версия>`, к которому прикреплены все собранные дистрибутивы — оба `.dmg`-файла (macOS, по одному на архитектуру) и `.msi`-файл (Windows) — так, чтобы платформа и архитектура каждого файла однозначно определялись по его имени и расширению (см. `desktop-app-packaging`, Requirement: Автономная установка без внешних зависимостей).

#### Scenario: Релиз содержит оба файла с различимыми именами
- **WHEN** релиз версии `1.2.0` опубликован
- **THEN** на странице релиза `v1.2.0` доступны для скачивания три файла — два `.dmg` с указанием arm64/aarch64 и x86_64 в именах и один `.msi` (Windows), все соответствуют выбранной версии, а платформа и архитектура каждого однозначно определяются по имени и расширению

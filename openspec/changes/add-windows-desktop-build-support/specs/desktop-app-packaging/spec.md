## MODIFIED Requirements

### Requirement: Автономная установка без внешних зависимостей
Система SHALL распространяться как установщик под каждую поддерживаемую операционную систему — macOS (`.dmg`, под архитектуру процессора конечного пользователя: Intel x86_64 или Apple Silicon arm64) и Windows (`.msi`, x86_64; Windows 10 и 11 — Windows 7 не поддерживается, так как используемый JDK 21 её официально не поддерживает) — после установки которого приложение запускается без необходимости отдельно устанавливать Java Runtime или сервер базы данных. Установщики под разные операционные системы/архитектуры SHALL иметь различимые имена файлов, чтобы пользователь мог однозначно выбрать подходящий для своей машины.

#### Scenario: Запуск на чистой машине
- **WHEN** пользователь без установленной Java и без запущенного сервера БД устанавливает и запускает приложение
- **THEN** приложение успешно запускается и становится пригодным для работы

#### Scenario: Выбор установщика под архитектуру Mac
- **WHEN** пользователь собирается установить приложение на Mac с определённой архитектурой процессора (Intel или Apple Silicon)
- **THEN** доступен установщик, чьё имя файла явно указывает на эту архитектуру, и после установки приложение работает нативно (без эмуляции) на этой архитектуре

#### Scenario: Выбор установщика под Windows
- **WHEN** пользователь собирается установить приложение на Windows 10 или 11
- **THEN** доступен установщик `.msi` — платформа однозначно определяется расширением файла, имя отличимо от macOS-установщиков, — и после установки приложение запускается без необходимости отдельно устанавливать Java Runtime

### Requirement: Замена версии при повторной установке
Установка нового установщика (`.dmg` на macOS, `.msi` на Windows) с более новой версией SHALL заменять существующую установку той же версии приложения, а не создавать вторую независимую копию приложения в системе.

#### Scenario: Повторная установка новой версии
- **WHEN** пользователь устанавливает установщик с более новой версией, имея уже установленную предыдущую версию приложения на той же операционной системе
- **THEN** в системе остаётся одна установленная копия приложения — обновлённая версия

## ADDED Requirements

### Requirement: Допустимые размеры полотна ФАНТОМ 01
Для leaf_type ФАНТОМ 01 (`LT-045`) ДОЛЖНЫ (SHALL) существовать строки `liner_dimension_option` со значением `is_standard = true` для длины (`DT-001`) 400, 600, 700 и 800 мм и для высоты (`DT-002`) 2000 и 2100 мм.

#### Scenario: Каталог отдаёт стандартные длины ФАНТОМ 01
- **WHEN** запрашивается список допустимых значений длины для leaf_type ФАНТОМ 01
- **THEN** в списке присутствуют ровно значения 400, 600, 700 и 800 мм, каждое помечено как стандартное

#### Scenario: Каталог отдаёт стандартные высоты ФАНТОМ 01
- **WHEN** запрашивается список допустимых значений высоты для leaf_type ФАНТОМ 01
- **THEN** в списке присутствуют ровно значения 2000 и 2100 мм, каждое помечено как стандартное

### Requirement: Толщина полотна ФАНТОМ 01
Для leaf_type ФАНТОМ 01 (`LT-045`) ДОЛЖНА (SHALL) существовать строка `liner_dimension_option` для толщины (`DT-003`) со значением 44 мм и `is_standard = true` — базовая (стандартная по умолчанию) толщина полотна. Толщина 59 мм для ФАНТОМ 01 доступна как дополнительная опция наравне со стандартной (см. capability `door-configuration-catalog`, «Опция толщины полотна 59 мм по коллекциям» — коллекция Фантом уже входит в этот список).

#### Scenario: Каталог отдаёт стандартную толщину 44 мм для ФАНТОМ 01
- **WHEN** запрашивается список допустимых значений толщины для leaf_type ФАНТОМ 01
- **THEN** в списке присутствует значение 44 мм, помеченное как стандартное

#### Scenario: Толщина 59 мм доступна наравне со стандартной
- **WHEN** запрашивается список допустимых значений толщины для leaf_type ФАНТОМ 01
- **THEN** в списке присутствуют ровно два значения — 44 и 59 мм, оба помечены как стандартные

### Requirement: Единственный совместимый короб для ФАНТОМ 01
Door_configuration для leaf_type ФАНТОМ 01 (`LT-045`) ДОЛЖНА (SHALL) ссылаться исключительно на frame_type «ФАНТОМ» (`FT-001`) — ни один другой frame_type для этой модели полотна не допускается. Реверсивное исполнение короба («короб Фантом реверс») не является отдельным frame_type — это тот же frame_type `FT-001` со значением `is_reverse = true` у соответствующей строки `door_configuration` (см. capability `door-configuration-catalog`, «Структура признака реверса door_configuration»).

#### Scenario: У ФАНТОМ 01 нет конфигураций с другими коробами
- **WHEN** запрашивается каталог конфигураций для leaf_type ФАНТОМ 01
- **THEN** среди его door_configuration нет ни одной строки, ссылающейся на frame_type, отличный от «ФАНТОМ» (`FT-001`)

#### Scenario: Обычный и реверсивный вариант используют один и тот же короб
- **WHEN** запрашивается каталог конфигураций для leaf_type ФАНТОМ 01
- **THEN** среди его door_configuration есть строки как с `is_reverse = false`, так и с `is_reverse = true`, и все они ссылаются на один и тот же frame_type «ФАНТОМ» (`FT-001`)

### Requirement: Сочетания реверса, четверти и кромки для ФАНТОМ 01
Для leaf_type ФАНТОМ 01 (`LT-045`) в каталоге ДОЛЖНЫ (SHALL) существовать door_configuration для короба «ФАНТОМ» (`FT-001`) в следующих сочетаниях `is_reverse`/«Четверть» (`has_quarter`)/кромки, и никаких других:
- `is_reverse = false`, «Четверть» = false — без кромки, и отдельно с кромкой «ПРЯМАЯ КРОМКА ПО ПЕРИМЕТРУ ПОЛОТНА» (`ET-001`);
- `is_reverse = false`, «Четверть» = true — без кромки, и отдельно с кромкой «КРОМКА ДЛЯ ПОЛОТНА С ЧЕТВЕРТЬЮ ПО ПЕРИМЕТРУ» (`ET-002`);
- `is_reverse = true`, «Четверть» = true (обязательно — см. «Заполнение атрибута «Четверть» для существующих конфигураций») — без кромки, и отдельно с кромкой `ET-002`.

Строк с `is_reverse = true` и «Четверть» = false для ФАНТОМ 01 НЕ ДОЛЖНО (SHALL NOT) существовать. Строк, ссылающихся на `ET-001` при «Четверть» = true или на `ET-002` при «Четверть» = false, НЕ ДОЛЖНО (SHALL NOT) существовать (общее правило «Соответствие вида кромки и атрибута «Четверть»» применяется без исключений для этой модели). Ни door_casing_type, ни frame_extensions_type у door_configuration ФАНТОМ 01 не задаются — короб «ФАНТОМ» не комплектуется наличником и добором ни для одной модели полотна.

#### Scenario: Обычное открывание доступно с четвертью и без
- **WHEN** запрашивается каталог конфигураций для leaf_type ФАНТОМ 01
- **THEN** среди door_configuration с `is_reverse = false` есть строки с «Четверть» = false и строки с «Четверть» = true

#### Scenario: Реверсивное открывание всегда с четвертью
- **WHEN** запрашивается каталог конфигураций для leaf_type ФАНТОМ 01
- **THEN** все door_configuration с `is_reverse = true` имеют «Четверть» = true, и ни одной строки с `is_reverse = true` и «Четверть» = false не существует

#### Scenario: Кромка независима от короба и доступна в трёх вариантах на каждое допустимое сочетание
- **WHEN** запрашивается каталог конфигураций для leaf_type ФАНТОМ 01
- **THEN** для каждого допустимого сочетания `is_reverse`/«Четверть» существует вариант без кромки, а также вариант с кромкой, соответствующей значению «Четверть» этого сочетания (`ET-001` при «Четверть» = false, `ET-002` при «Четверть» = true)

#### Scenario: У ФАНТОМ 01 нет наличника и добора
- **WHEN** запрашивается каталог конфигураций для leaf_type ФАНТОМ 01
- **THEN** ни одна из его door_configuration не ссылается на door_casing_type или frame_extensions_type

### Requirement: Доступность зеркала для ФАНТОМ 01
Для leaf_type ФАНТОМ 01 (`LT-045`) ДОЛЖНЫ (SHALL) существовать строки `mirror_finish_option` для всех существующих `mirror_finish_type` («Глухое плоское полотно с зеркалом с одной стороны», «...с фацетом с одной стороны», «...серое/бронза с одной стороны») — зеркало является доступной, но не обязательной опцией исполнения полотна. Как следствие наличия этих строк, `panel_type` этого leaf_type ДОЛЖЕН (SHALL) быть равен «с зеркалом» (`MIRRORED`), согласно общему требованию «Тип полотна leaf_type».

#### Scenario: ФАНТОМ 01 показывает все исполнения зеркала
- **WHEN** запрашивается каталог конфигураций и leaf_type данной door_configuration — ФАНТОМ 01
- **THEN** в ответе для leaf-компонента присутствуют все три исполнения зеркала: «Базовое», «С фацетом» и «Серое/бронза»

#### Scenario: ФАНТОМ 01 классифицирован как полотно с зеркалом
- **WHEN** запрашивается leaf_type ФАНТОМ 01
- **THEN** его panel_type равен «с зеркалом» (`MIRRORED`)

### Requirement: Цена полотна ФАНТОМ 01
Для leaf_type ФАНТОМ 01 (`LT-045`) ДОЛЖНА (SHALL) существовать ровно одна строка `configuration_price`, принадлежащая этому leaf_type (без ссылок на конкретную длину, высоту, толщину или цвет), с retail_price = 10728 и dealer_price = 18255.

#### Scenario: Цена ФАНТОМ 01 доступна в каталоге
- **WHEN** запрашивается цена полотна для leaf_type ФАНТОМ 01
- **THEN** возвращается retail_price = 10728 и dealer_price = 18255

### Requirement: Отсутствие цветовых опций у ФАНТОМ 01
Для leaf_type ФАНТОМ 01 (`LT-045`) НЕ ДОЛЖНО (SHALL NOT) существовать ни одной строки `colour_option` — по конструкции у полотна этой коллекции нет выбора цвета (решение подтверждено фабрикой, см. `door-configuration-catalog`, «Цвет «Другой цвет из коллекции RAL и NCS»»).

#### Scenario: У ФАНТОМ 01 нет допустимых цветов
- **WHEN** запрашивается список допустимых colour_option для leaf_type ФАНТОМ 01
- **THEN** список пуст

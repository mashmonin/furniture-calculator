- [x] 1.3 (доп., не было в исходном плане) Найдена и устранена реальная причина блёклости — не сам по себе выбор оттенка Ant Design, а `frontend/src/index.css`: нетронутый шаблонный CSS от `npm create vite` со своим `:root { color: var(--text) }` (`--text: #6b6375`, блёклый серо-сиреневый) — наследуемое свойство перекрывало часть текста поверх темы antd. Заменено на `--text: #000`, убран `-webkit-font-smoothing: antialiased` (в WebKit истончает штрихи).
- [x] 1.4 (доп.) Даже после этого чисто чёрный текст в JavaFX WebView визуально оставался светлее, чем должен — подтверждено диагностикой (временная ярко-красная тема показала, что стили применяются корректно, значит дело в самом сглаживании WebKit). Добавлена `-webkit-text-stroke: 0.35px currentColor` в `index.css` — тонкая обводка текста тем же цветом компенсирует "съедание" тонких штрихов антиалиасингом; в обычном браузере эффект незаметен.

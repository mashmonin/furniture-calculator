## MODIFIED Requirements

### Requirement: Каталог фурнитуры из файла
Экран сервиса ДОЛЖЕН (SHALL) показывать каталог фурнитуры прайс-листа `prays_list_furnitura_tsfo_01_02_2026` (`PL-003`) под лентой дверей. Вверху каталога — фильтры: бренд (выпадающий список: HAUSDOORS, Fantom, Vantage; при первом открытии страницы и после сброса подбора бренд НЕ ВЫБРАН — поле пустое, с подсказкой «Выберите бренд»), «Элемент» (выпадающий список разделов выбранного бренда, названия без префикса бренда), «Цвет» (выпадающий список цветов выбранного бренда и элемента, рядом с «Элемент») и текстовый поиск по модели, цвету и артикулу. Пока бренд не выбран, фильтры «Элемент» и «Цвет» недоступны, а блок «Модель» показывает пустой список с подсказкой «Выберите бренд». Ниже — блок «Модель» со списком записей на всю ширину экрана: ОДНА запись = модель выбранного бренда + ОДИН цвет + одна розничная цена за единицу (цена дилера НЕ ДОЛЖНА (SHALL NOT) показываться); в строке записи — название модели, цвет, цена розница и кнопка «+»; все элементы строки, включая кнопку «+», ДОЛЖНЫ (SHALL) помещаться в границах списка (цвет при нехватке ширины сужается). Название раздела под названием модели НЕ ДОЛЖНО (SHALL NOT) выводиться. Запись выбирается нажатием на строку (подсвечивается), кнопка «+» в строке добавляет эту запись к выбранной двери. Отдельных списков «Цвет» и блока «Выбранная модель» нет. Смена бренда сбрасывает фильтры «Элемент» и «Цвет», смена элемента — фильтр «Цвет». Фурнитура других прайс-листов в этом каталоге НЕ ДОЛЖНА (SHALL NOT) показываться.

#### Scenario: Выбор начинается с бренда
- **WHEN** пользователь открывает сервис «Фурнитура»
- **THEN** бренд не выбран (поле пустое, подсказка «Выберите бренд»), в блоке «Модель» пустой список с подсказкой «Выберите бренд», фильтры «Элемент» и «Цвет» недоступны

#### Scenario: Список появляется после выбора бренда
- **WHEN** пользователь выбирает бренд «Fantom»
- **THEN** в списке записей — только записи моделей этого бренда, фильтры «Элемент» и «Цвет» становятся доступными

#### Scenario: Одна запись — один цвет и одна цена
- **WHEN** у модели «Дверная ручка Fantom "Кассандра"» четыре цвета
- **THEN** в списке четыре отдельные записи, в каждой — один цвет и одна цена розницы

#### Scenario: Фильтр «Элемент»
- **WHEN** пользователь выбирает элемент «Фиксаторы»
- **THEN** в списке остаются только записи этого элемента выбранного бренда

#### Scenario: Фильтр «Цвет»
- **WHEN** пользователь выбирает цвет «Матовый черный»
- **THEN** в списке остаются только записи этого цвета выбранного бренда и элемента

#### Scenario: Поиск
- **WHEN** пользователь вводит артикул, цвет или часть названия модели
- **THEN** в списке остаются только записи выбранного бренда, у которых совпадает название модели, цвет или артикул

### Requirement: Добавление фурнитуры к двери
Пользователь ДОЛЖЕН (SHALL) иметь возможность добавить цветовой вариант каталога к выбранной двери кнопкой «+» в строке записи (количество 1). Если такой вариант фурнитуры у двери уже есть, его количество ДОЛЖНО (SHALL) увеличиться на 1, а не создаваться дубликат; изменить количество можно в списке фурнитуры двери (см. «Изменение и удаление добавленной фурнитуры»). После добавления цена позиции корзины за единицу, её детализация и итог по заказу ДОЛЖНЫ (SHALL) пересчитываться с учётом добавленной фурнитуры; полотно и прочие компоненты двери НЕ ДОЛЖНЫ (SHALL NOT) меняться. После успешного добавления подбор ДОЛЖЕН (SHALL) сбрасываться: снимается подсветка выбранной записи, очищаются фильтры «Бренд», «Элемент», «Цвет» и строка поиска (бренд снова не выбран, список «Модель» пуст с подсказкой «Выберите бренд»); выбранная дверь остаётся прежней. При ошибке добавления выбор и фильтры НЕ ДОЛЖНЫ (SHALL NOT) сбрасываться. Одновременно с успешным добавлением ДОЛЖНА (SHALL) проигрываться анимация «частицы», летящей от нажатой кнопки «+» к карточке выбранной двери (тем же эффектом, что и при добавлении конфигурации в корзину).

#### Scenario: Добавление новой фурнитуры
- **WHEN** выбрана дверь с ценой 17 761 ₽ за единицу и к ней добавляется ручка по розничной цене 3 050 ₽
- **THEN** цена этой позиции корзины за единицу становится 20 811 ₽, в детализации появляется строка «Фурнитура» с этой ручкой

#### Scenario: Повторное добавление увеличивает количество
- **WHEN** к двери добавляется вариант фурнитуры, который у неё уже есть в количестве 1
- **THEN** у двери остаётся одна строка этой фурнитуры с количеством 2

#### Scenario: Сброс подбора после добавления
- **WHEN** выбраны бренд «Fantom», элемент, цвет, введён поиск, подсвечена запись, и пользователь нажимает «+» в её строке
- **THEN** после добавления бренд, элемент, цвет и поиск пусты, подсветки записи нет, в блоке «Модель» пустой список с подсказкой «Выберите бренд», выбранная дверь прежняя

#### Scenario: Ошибка не сбрасывает выбор
- **WHEN** расчёт фурнитуры при добавлении завершается ошибкой
- **THEN** показывается сообщение об ошибке, бренд, фильтры, поиск и подсветка записи остаются как были

#### Scenario: Частица летит к выбранной двери
- **WHEN** пользователь нажимает «+» и добавление проходит успешно
- **THEN** от кнопки «+» к карточке выбранной двери летит частица и угасает по пути

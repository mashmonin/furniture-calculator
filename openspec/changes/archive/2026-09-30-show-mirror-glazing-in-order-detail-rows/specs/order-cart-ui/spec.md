## MODIFIED Requirements

### Requirement: Разворачиваемая детализация позиции корзины
Под каждой строкой позиции таблица ДОЛЖНА (SHALL) всегда показывать, на всю ширину таблицы, полосу с текстом «Детализация конфигурации» и иконкой-шевроном — отдельно от действий «Посмотреть»/«Удалить» (см. «Кнопка «Посмотреть» открывает конфигурацию в конфигураторе», «Удаление позиции из корзины») и не заменяющий их. Клик по этой полосе (или по иконке) ДОЛЖЕН (SHALL) показывать под ней вложенную таблицу детализации состава позиции по компонентам со столбцами: «Элемент» (тип компонента — Полотно/Кромка/Короб/Наличник/Добор/Декоративные элементы/Фурнитура), «Наименование» (конкретная модель/позиция), «Размеры», «Цвет», «Кол-во», «Цена дилер», «Цена клиенту», «Сумма дилер», «Сумма клиенту» — цена «за единицу» и «сумма» совпадают для строк с количеством 1. Компонент «Короб» ДОЛЖЕН (SHALL) показываться ровно одной строкой на весь короб — его позиции состава (frame_post, см. door-configurator-ui, «Отображение позиций короба») в эту детализацию отдельными строками НЕ ДОЛЖНЫ (SHALL NOT) выводиться: цена строки «Короб» уже включает их сумму целиком (см. door-configuration-api, «Стоимость короба как сумма цен его стоек»), поэтому дублирование не требуется — состав короба по-прежнему виден в самом конфигураторе. Каждая позиция декоративного элемента ДОЛЖНА (SHALL) показываться отдельной строкой «Декоративные элементы» (без объединения одинаковых типов, тем же принципом, что и позиции фурнитуры), со столбцом «Размеры», содержащим длину типа в мм, и пустым столбцом «Цвет» (у decorative_element_type нет цвета). Данные строятся на фронтенде в момент добавления позиции в корзину из тех же каталожных и выбранных данных, что использует сам конфигуратор (см. «Хранение корзины в localStorage»), без нового обращения к backend при разворачивании/сворачивании. Повторный клик по полосе уже развёрнутой позиции ДОЛЖЕН (SHALL) сворачивать вложенную таблицу обратно (полоса и её текст с иконкой остаются на месте — сворачивается только таблица под ней). Детализация показывает данные ровно для одной единицы изделия — не умножается на количество позиции.

Сразу под строкой «Полотно» (перед строкой «Кромка», если она есть) детализация ДОЛЖНА (SHALL) содержать отдельную строку «Исполнение зеркала» с наименованием выбранного исполнения — если для полотна этой позиции выбрано исполнение зеркала, — и/или отдельную строку «Вид остекления» с наименованием выбранного вида — если для полотна выбран вид остекления (полотно не может иметь выбранными оба одновременно). Если ни то, ни другое не выбрано, ни одна из этих строк не добавляется. Столбцы «Размеры» и «Цвет» этой строки и все четыре ценовых столбца ДОЛЖНЫ (SHALL) отображаться пустыми, а не «—» — цена (и размер/цвет) этой строке в принципе неприменимы, что отличается от «цена не найдена» у обычного компонента; лишние прочерки у строки без собственной цены мешают восприятию. Столбец «Кол-во» показывает 1.

#### Scenario: Полоса «Детализация конфигурации» видна под каждой строкой
- **WHEN** в корзине есть хотя бы одна позиция
- **THEN** под строкой этой позиции, на всю ширину таблицы, видна полоса с текстом «Детализация конфигурации» и иконкой-шевроном, независимо от того, развёрнута детализация или нет

#### Scenario: Клик по полосе показывает вложенную таблицу детализации
- **WHEN** пользователь кликает по полосе «Детализация конфигурации» (или по её иконке) у позиции корзины
- **THEN** под этой полосой появляется вложенная таблица с построчной детализацией по каждому компоненту конфигурации (полотно, кромка, короб, наличник, добор, декоративные элементы, фурнитура — какие из них присутствуют в этой конфигурации), с наименованием, размерами, цветом, количеством и ценами за одну единицу; иконка меняется на противоположную (стрелка вверх)

#### Scenario: Позиции декоративных элементов показаны отдельными строками
- **WHEN** позиция корзины содержит две позиции декоративных элементов с разными типами
- **THEN** детализация показывает две отдельные строки «Декоративные элементы» — по одной на каждую позицию, каждая со своим наименованием, длиной в столбце «Размеры», количеством и ценой/суммой

#### Scenario: Состав короба не дублируется отдельными строками
- **WHEN** конфигурация содержит короб, чей список позиций frame_post из каталога содержит несколько записей (например, незарезную стойку и комплект зарезных стоек)
- **THEN** в детализации позиции короб показан ровно одной строкой «Короб» с суммарной ценой; отдельных строк на каждую позицию его состава нет

#### Scenario: Повторный клик сворачивает детализацию
- **WHEN** детализация позиции уже развёрнута, и пользователь снова кликает по полосе «Детализация конфигурации»
- **THEN** вложенная таблица детализации скрывается, а сама полоса с текстом и иконкой (уже в исходном положении) остаётся видна

#### Scenario: Позиция без сохранённой детализации показывает пояснение вместо пустой таблицы
- **WHEN** у позиции корзины нет построчной детализации (например, она была добавлена в корзину до появления этого поля хранения) и пользователь разворачивает полосу «Детализация конфигурации»
- **THEN** вместо пустой таблицы показано пояснение, что детализация недоступна для этой позиции, и что нужно добавить конфигурацию в корзину заново

#### Scenario: Исполнение зеркала показано отдельной строкой под полотном
- **WHEN** позиция корзины содержит полотно с выбранным исполнением зеркала
- **THEN** в развёрнутой детализации сразу под строкой «Полотно» идёт строка «Исполнение зеркала» с наименованием выбранного исполнения; столбцы «Размеры», «Цвет» и все четыре ценовых столбца пусты (без «—»), количество равно 1

#### Scenario: Вид остекления показан отдельной строкой под полотном
- **WHEN** позиция корзины содержит полотно с выбранным видом остекления
- **THEN** в развёрнутой детализации сразу под строкой «Полотно» идёт строка «Вид остекления» с наименованием выбранного вида; столбцы «Размеры», «Цвет» и все четыре ценовых столбца пусты (без «—»), количество равно 1

#### Scenario: Полотно без зеркала и остекления не добавляет лишних строк
- **WHEN** позиция корзины содержит полотно, для которого не выбраны ни исполнение зеркала, ни вид остекления
- **THEN** в развёрнутой детализации под строкой «Полотно» нет дополнительной строки с исполнением зеркала или видом остекления

## ADDED Requirements

### Requirement: Совместимость диапазона длины наличников «Модо»/«Онда» с высотой полотна
Если в запросе расчёта стоимости для doorCasing-компонента, чей door_casing_type имеет код из набора кодов наличников «Модо»/«Онда» (DCT-003, DCT-004), выбрана liner_dimension_option оси «Длина» (диапазон [min_value, max_value], где отсутствующая граница означает открытую с этой стороны границу, а при отсутствующем max_value верхней границей считается value), система ДОЛЖНА (SHALL) проверить, что значение высоты полотна, выбранное клиентом для leaf-компонента той же конфигурации, находится внутри этого диапазона. Если высота полотна не выбрана клиентом, либо выбранный диапазон её не покрывает, эндпоинт ДОЛЖЕН (SHALL) отвечать ошибкой 400 и не выполнять расчёт. Для door_casing_type с кодом вне этого набора эта проверка не выполняется, даже если у него есть опции длины.

#### Scenario: Высота полотна внутри диапазона длины наличника — расчёт выполняется
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) попадает в диапазон [min_value, max_value] выбранной длины наличника (doorCasing с door_casing_type кодом из набора DCT-003–DCT-004)
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки

#### Scenario: Высота полотна вне диапазона длины наличника — 400
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) не попадает в диапазон [min_value, max_value] выбранной длины наличника «Модо»/«Онда»
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Длина наличника выбрана без высоты полотна — 400
- **WHEN** отправляется запрос расчёта стоимости, в котором для doorCasing-компонента с door_casing_type кодом из набора DCT-003–DCT-004 выбрана liner_dimension_option оси «Длина», а для leaf-компонента высота не выбрана
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Высота полотна в разрыве между диапазонами длины наличника — 400
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) не попадает ни в один из непересекающихся диапазонов, заданных для опций длины наличника «Модо»/«Онда», но выбрана одна из этих опций длины
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Проверка не применяется к другим наличникам и компонентам
- **WHEN** отправляется запрос расчёта стоимости, где для doorCasing-компонента с door_casing_type кодом вне набора (например, «Эво», DCT-001) выбрана liner_dimension_option оси «Длина», независимо от выбранной высоты полотна
- **THEN** эндпоинт выполняет расчёт как обычно, без проверки диапазона высоты полотна для этого компонента

### Requirement: Обязательность длины для наличников «Модо»/«Онда»
Если в запросе расчёта стоимости для doorCasing-компонента, чей door_casing_type имеет код из набора кодов наличников «Модо»/«Онда» (DCT-003, DCT-004), не передан id liner_dimension_option оси «Длина» (lengthOptionId отсутствует), эндпоинт ДОЛЖЕН (SHALL) отвечать ошибкой 400 и не выполнять расчёт — длина для этих наличников обязательна, а не опциональна, как для прочих наличников. Это гарантирует, что для высоты полотна, не покрытой ни одним диапазоном длины наличника «Модо»/«Онда» (см. «Совместимость диапазона длины наличников «Модо»/«Онда» с высотой полотна»), расчёт с таким наличником невозможен ни при каком запросе — в том числе при полном отсутствии выбранной длины.

#### Scenario: Наличник «Модо»/«Онда» без выбранной длины — 400
- **WHEN** отправляется запрос расчёта стоимости, где для doorCasing-компонента с door_casing_type кодом из набора DCT-003–DCT-004 не передан lengthOptionId
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт, независимо от того, выбрана ли высота полотна

#### Scenario: Прочие наличники не требуют обязательной длины
- **WHEN** отправляется запрос расчёта стоимости, где для doorCasing-компонента с door_casing_type кодом вне набора DCT-003–DCT-004 не передан lengthOptionId
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки, связанной с отсутствием длины

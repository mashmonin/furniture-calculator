## ADDED Requirements

### Requirement: Условное отображение длины наличников «Модо»/«Онда» по высоте полотна
Группа кнопок «Длина» для doorCasing-компонента, чей тип наличника имеет код из набора кодов наличников «Модо»/«Онда» (DCT-003, DCT-004), ДОЛЖНА (SHALL) оставаться скрытой, пока клиент не выбрал значение высоты для leaf-компонента выбранной конфигурации. После выбора высоты полотна группа «Длина» этого doorCasing-компонента ДОЛЖНА (SHALL) показывать только те его опции длины из каталога, чей диапазон [min_value, max_value] (или [min_value, value], если max_value не задан) покрывает выбранную высоту полотна; остальные шаги и группы опций продолжают отображаться по действующим правилам без изменений. Для doorCasing-компонента с типом наличника вне этого набора группа «Длина» отображается без этой фильтрации, как раньше.

#### Scenario: Высота полотна ещё не выбрана — группа длины наличника скрыта
- **WHEN** выбранная конфигурация содержит doorCasing-компонент с типом наличника из набора DCT-003–DCT-004 и допустимыми опциями длины, но клиент ещё не выбрал высоту для leaf-компонента
- **THEN** группа кнопок «Длина» для этого doorCasing-компонента не отображается

#### Scenario: После выбора высоты полотна показывается только совместимый диапазон длины
- **WHEN** клиент выбрал высоту полотна, и среди опций длины doorCasing-компонента с типом наличника из набора есть диапазон, покрывающий эту высоту
- **THEN** группа «Длина» этого doorCasing-компонента показывает только эту опцию (опции, чей диапазон эту высоту не покрывает, не показываются)

#### Scenario: Высота полотна в разрыве между диапазонами — группа длины наличника пуста
- **WHEN** клиент выбрал высоту полотна, которая не попадает ни в один из диапазонов опций длины doorCasing-компонента с типом наличника из набора (например, 2600–2850 или 2900–2950)
- **THEN** группа «Длина» этого doorCasing-компонента не показывает ни одной опции

#### Scenario: Изменение высоты полотна сбрасывает выбор длины наличника
- **WHEN** клиент меняет ранее выбранную высоту полотна после того, как длина наличника «Модо»/«Онда» уже была выбрана
- **THEN** выбор длины этого doorCasing-компонента сбрасывается, а группа «Длина» пересчитывается по новой высоте полотна

#### Scenario: Прочие наличники не фильтруются по высоте полотна
- **WHEN** выбранная конфигурация содержит doorCasing-компонент с типом наличника вне набора DCT-003–DCT-004, и у него есть опции длины
- **THEN** группа «Длина» этого doorCasing-компонента показывает все его опции длины независимо от выбранной высоты полотна, как и до этого изменения

### Requirement: Исключение наличников «Модо»/«Онда» из каскада при несовместимой высоте полотна
Если клиент уже выбрал высоту полотна для leaf-компонента, и ни один диапазон длины типа наличника из набора кодов «Модо»/«Онда» (DCT-003, DCT-004) её не покрывает, этот тип наличника ДОЛЖЕН (SHALL) быть исключён из списка доступных типов на шаге каскадного выбора наличника. Если высота полотна ещё не выбрана, типы наличника из набора остаются в списке доступных типов, как раньше. Это дополнение к требованию «Условное отображение длины наличников «Модо»/«Онда» по высоте полотна», а не замена: даже если это исключение по какой-либо причине не сработало, совместимость по-прежнему проверяется на бэкенде при расчёте стоимости.

#### Scenario: Тип наличника скрыт из списка при несовместимой высоте полотна
- **WHEN** клиент уже выбрал высоту полотна, которая не попадает ни в один диапазон длины типа наличника из набора DCT-003–DCT-004
- **THEN** этот тип наличника не отображается среди доступных типов на шаге каскадного выбора наличника

#### Scenario: Тип наличника остаётся в списке, пока высота полотна не выбрана
- **WHEN** клиент ещё не выбрал высоту полотна
- **THEN** типы наличника «Модо»/«Онда» отображаются среди доступных типов на шаге каскадного выбора наличника, как и до этого изменения

#### Scenario: Тип наличника возвращается в список при совместимой высоте полотна
- **WHEN** клиент выбрал высоту полотна, которая попадает в один из диапазонов типа наличника «Модо»/«Онда»
- **THEN** этот тип наличника отображается среди доступных типов на шаге каскадного выбора наличника

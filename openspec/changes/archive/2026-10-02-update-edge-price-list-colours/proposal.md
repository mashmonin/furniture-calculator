## Why

Вышел обновлённый прайс-лист на кромки. В нём изменился набор цветов: цвет «Бронза» снят, добавлены «Шоколад», «Шампань» и «Никель», а цена «Золото матовое» снизилась. Каталог должен соответствовать актуальному прайсу.

## What Changes

- Для обоих видов кромки — «ПРЯМАЯ КРОМКА ПО ПЕРИМЕТРУ ПОЛОТНА» (`ET-001`) и «КРОМКА ДЛЯ ПОЛОТНА С ЧЕТВЕРТЬЮ ПО ПЕРИМЕТРУ» (`ET-002`) — и для всех моделей (кромка не зависит от коллекции) набор цветов становится: «Хром матовый», «Чёрный», «Золото матовое», «Шоколад», «Шампань», «Никель», «Покраска по RAL».
- Цвет «Бронза» (`CT-024`) перестаёт быть доступным для кромки, его цены для кромки удаляются.
- Добавляются новые цвета справочника: «Шоколад», «Шампань», «Никель».
- Обновляются цены кромки по четырём диапазонам высоты полотна (до 2100, 2150–2400, 2450–2700, 2750–2950 мм): для «Золото матовое» — новые (сниженные) цены, для «Шоколад», «Шампань», «Никель» — те же цены, что у «Золото матовое». Цены «Хром матовый», «Чёрный» и «Покраска по RAL» не меняются.
- Структура справочников и схема БД не меняются — только данные (новый Liquibase changeset).

### Modified Capabilities
- `door-configuration-catalog`: фиксируется набор цветов кромки и их цены (комплект, розница и дилерская) по диапазонам высоты.

## Impact

- Backend: новый Liquibase changeset (данные `colour_type`, `colour_option`, `configuration_price`) и подключение в `db.changelog-master.yaml`.
- Frontend и API: изменений кода нет — цвета и цены кромки отдаются из каталога; в выпадающем списке цветов кромки изменится состав.
- Уже сохранённые заказы/корзины с цветом «Бронза» у кромки (если такие есть) — см. риски в design.md.

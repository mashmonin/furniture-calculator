## Context

Цвета кромки хранятся в `colour_option` (владелец — `edge_type`), цены — в `configuration_price` (`edge_type_id` + `height_option_id` + `colour_option_id`, поля `retail_price`/`dealer_price`). Исходные данные заведены в changeset `0025` для `ET-001` и `ET-002` с цветами `CT-023..CT-027` (Хром матовый, Бронза, Чёрный, Золото матовое, Покраска по RAL) и четырьмя диапазонами высоты (`liner_dimension_option` оси `DT-002`). Кромка не привязана к коллекции, поэтому изменение действует для всех моделей. Максимальный существующий код цвета — `CT-029`.

В прайсе первая цифра — дилерская цена, вторая — розничная (так же, как в `0025`: «6 899 / 12 074» → `dealer_price = 6899`, `retail_price = 12074`).

## Goals / Non-Goals

**Goals:**
- Привести цвета и цены кромки в соответствие с новым прайсом.

**Non-Goals:**
- Изменение диапазонов высоты, видов кромки, правил «Четверть»/реверс.
- Изменение цветов, не относящихся к кромке (`CT-023`, `CT-025`, `CT-027`, `CT-028` используются ещё у стоек ФАНТОМ — не трогаем).

## Decisions

1. **Новый changeset, `0025` не редактируется** (конвенция проекта). Номер — следующий свободный после `0112`.
2. **Новые цвета** — `CT-030` «Шоколад», `CT-031` «Шампань», `CT-032` «Никель» в `colour_type`. Альтернатива — переиспользовать существующие цвета; таких в справочнике нет.
3. **«Бронза» (`CT-024`)**: удаляются `configuration_price` и `colour_option` для кромки (сначала цены из-за FK). Сама запись `colour_type` `CT-024` остаётся: она не используется другими владельцами, но её удаление не нужно для задачи и безопаснее для ссылочной целостности.
4. **Цены** обновляются `UPDATE` по ключу (вид кромки, диапазон высоты, цвет) для «Золото матовое»; для новых цветов — `INSERT` (`colour_option` для `ET-001`/`ET-002`, затем `configuration_price`) с теми же значениями, что у «Золото матовое». Одна таблица значений `VALUES`, как в `0025-4`.
5. Rollback — по возможности обратные операции (вернуть «Бронза» и старые цены «Золото матовое», удалить новые цвета); если не получается — явно `rollback: empty` с комментарием.

## Risks / Trade-offs

- [Сохранённые заказы/корзина с кромкой «Бронза» могут перестать валидироваться] → при реализации проверить, хранит ли заказ id цвета или снимок названия; при зависимости — не удалять `colour_option`, а обработать отдельно.
- [Ошибка при переносе цен из прайса] → в задачах — проверочный SQL/тест, сверяющий все 2 × 4 × 7 = 56 цен с прайсом.

## ADDED Requirements

### Requirement: Цвета кромки и их цены
Для каждого edge_type («ПРЯМАЯ КРОМКА ПО ПЕРИМЕТРУ ПОЛОТНА», `ET-001`, и «КРОМКА ДЛЯ ПОЛОТНА С ЧЕТВЕРТЬЮ ПО ПЕРИМЕТРУ», `ET-002`) ДОЛЖНЫ (SHALL) существовать строки `colour_option` ровно для цветов «Хром матовый», «Чёрный», «Золото матовое», «Шоколад», «Шампань», «Никель» и «Покраска по RAL». Цвет «Бронза» НЕ ДОЛЖЕН (SHALL NOT) быть доступен для кромки. Набор цветов не зависит от модели и коллекции полотна. Для каждого цвета и каждого диапазона высоты полотна («до 2100», «2150–2400», «2450–2700», «2750–2950» мм) ДОЛЖНА (SHALL) существовать строка `configuration_price` с розничной и дилерской ценой комплекта кромки, соответствующая таблицам ниже; цены «Шоколад», «Шампань» и «Никель» равны ценам «Золото матовое» для того же вида кромки и диапазона.

#### Scenario: Набор цветов кромки
- **WHEN** запрашиваются цвета для edge_type `ET-001` или `ET-002`
- **THEN** возвращаются ровно «Хром матовый», «Чёрный», «Золото матовое», «Шоколад», «Шампань», «Никель», «Покраска по RAL», а «Бронза» отсутствует

#### Scenario: Цена «Золото матовое» снижена
- **WHEN** запрашивается цена кромки `ET-001`, цвет «Золото матовое», высота полотна до 2100 мм
- **THEN** розничная цена равна 15 703, дилерская — 8 973

#### Scenario: Новые цвета оцениваются как «Золото матовое»
- **WHEN** запрашивается цена кромки `ET-002`, цвет «Никель», высота полотна 2150–2400 мм
- **THEN** розничная цена равна 19 555, дилерская — 11 174

#### Scenario: Цены неизменённых цветов сохраняются
- **WHEN** запрашивается цена кромки `ET-001`, цвет «Хром матовый», высота полотна 2450–2700 мм
- **THEN** розничная цена равна 14 168, дилерская — 8 095

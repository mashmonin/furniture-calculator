## ADDED Requirements

### Requirement: Длина наличников «Light»/«Modo» и доборов «Neo» по высоте полотна
Наличники «Light» (`DCT-010`) и «Modo» (`DCT-011`) и доборы «Neo 100 мм» (`FET-014`) и «Neo 190 мм» (`FET-015`) ДОЛЖНЫ (SHALL) входить в наборы с диапазонным ограничением длины (как существующие наличники и доборы): длина определяется выбранной опцией, высота полотна должна лежать в её диапазоне, расчёт без выбранной длины отклоняется (400). Цена компонента ДОЛЖНА (SHALL) определяться явной строкой configuration_price для выбранной опции длины; процентные наценки не применяются: базовая и итоговая цена компонента равны, итог умножается только на выбранное количество.

#### Scenario: Наличник Light — цена по длине
- **WHEN** отправляется запрос расчёта для модели «Эмаль Лайт» с наличником «Light», высотой полотна 2000 и выбранной длиной наличника 2250
- **THEN** цена наличника за штуку — розница 1 094, дилер 663, без наценок

#### Scenario: Добор Neo 190 мм — цена по длине
- **WHEN** отправляется запрос расчёта для модели «Эмаль Лайт» с добором «Neo 190 мм», высотой полотна 2200 и выбранной длиной добора 2400
- **THEN** цена добора за штуку — розница 2 424, дилер 1 469, без наценок

#### Scenario: Длина вне диапазона высоты полотна
- **WHEN** выбрана длина наличника 2250, а высота полотна равна 2200
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Расчёт без длины наличника или добора
- **WHEN** отправляется запрос расчёта для конфигурации с наличником «Modo» или добором «Neo 100 мм» без выбранной длины
- **THEN** эндпоинт отвечает ошибкой 400

#### Scenario: Количество умножает цену за штуку
- **WHEN** для наличника «Modo» (высота полотна 2100, длина 2400) указано количество 2
- **THEN** цена компонента — розница 2 532, дилер 1 534

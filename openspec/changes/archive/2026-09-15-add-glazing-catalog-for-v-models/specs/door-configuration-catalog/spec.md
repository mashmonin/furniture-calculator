## ADDED Requirements

### Requirement: Структура glazing_type
Glazing_type ДОЛЖЕН (SHALL) хранить наименование вида остекления (name) — обязательное поле. Glazing_type — глобальный справочник, не привязанный к конкретному leaf_type или коллекции, без наценки к цене полотна.

Glazing_type ДОЛЖЕН (SHALL) содержать ровно следующие шесть строк: «Прозрачное», «Прозрачное серое», «Прозрачное бронза», «Сатинированное», «Сатинированное серое», «Сатинированное бронзовое».

#### Scenario: Правило требует name
- **WHEN** строка glazing_type вставляется без name
- **THEN** база данных отклоняет вставку

#### Scenario: Существуют шесть предустановленных видов остекления
- **WHEN** запрашивается справочник glazing_type
- **THEN** в нём присутствуют ровно шесть строк: «Прозрачное», «Прозрачное серое», «Прозрачное бронза», «Сатинированное», «Сатинированное серое», «Сатинированное бронзовое»

### Requirement: Владение glazing_option
Glazing_option ДОЛЖЕН (SHALL) ссылаться ровно на один glazing_type и ровно один leaf_type — какой вид остекления допустим для какой модели полотна. Комбинация glazing_type и leaf_type ДОЛЖНА (SHALL) быть уникальной. Как и mirror_finish_option, glazing_option ДОЛЖЕН (SHALL) владеться исключительно leaf_type.

#### Scenario: Запись glazing_option требует leaf_type и glazing_type
- **WHEN** строка glazing_option вставляется без ссылки на leaf_type или без ссылки на glazing_type
- **THEN** база данных отклоняет вставку

#### Scenario: Вид остекления не может повторяться для одного полотна
- **WHEN** для одного и того же leaf_type вставляется вторая строка glazing_option с уже существующим glazing_type
- **THEN** база данных отклоняет вставку

#### Scenario: Один и тот же вид остекления допустим для нескольких моделей полотна
- **WHEN** для одного glazing_type вставляются строки glazing_option для нескольких разных leaf_type
- **THEN** все строки сохраняются независимо

### Requirement: Допустимые виды остекления в каталоге конфигураций
Для leaf-компонента каждой door_configuration в ответе каталога конфигураций система ДОЛЖНА (SHALL) включать список видов остекления, допустимых для leaf_type этой конфигурации (определяется наличием строки glazing_option для пары этот leaf_type + вид остекления) — id (glazing_type.id) и наименование. Для компонентов, отличных от leaf (frame, edge, doorCasing, frameExtensions), список видов остекления ДОЛЖЕН (SHALL) быть пустым.

#### Scenario: Остеклённое полотно показывает допустимые виды остекления
- **WHEN** запрашивается каталог конфигураций и leaf_type данной door_configuration имеет строки glazing_option
- **THEN** в ответе для leaf-компонента этой конфигурации присутствует список этих видов остекления

#### Scenario: Полотно без видов остекления возвращает пустой список
- **WHEN** запрашивается каталог конфигураций и leaf_type данной door_configuration не имеет ни одной строки glazing_option
- **THEN** в ответе для leaf-компонента этой конфигурации список видов остекления пуст, запрос не завершается ошибкой

#### Scenario: Остальные компоненты не имеют видов остекления
- **WHEN** запрашивается каталог конфигураций
- **THEN** для frame-, edge-, doorCasing- и frameExtensions-компонентов список видов остекления в ответе всегда пуст

### Requirement: Остеклённые модели коллекций Гармония, Геометрия, Свобода и Элегант
Для leaf_type со следующими кодами panel_type ДОЛЖЕН (SHALL) быть равен «остеклённое», и им ДОЛЖНЫ (SHALL) быть доступны все шесть видов остекления (строка glazing_option на каждый):
- `LT-017` (ЭЛЕГАНТ 01V), `LT-018` (ЭЛЕГАНТ 02V), `LT-019` (ЭЛЕГАНТ 021V)
- `LT-023` (ГАРМОНИЯ 01V), `LT-024` (ГАРМОНИЯ 02V), `LT-025` (ГАРМОНИЯ 021V)
- `LT-030` (СВОБОДА 01V), `LT-031` (СВОБОДА 02V), `LT-032` (СВОБОДА 021V), `LT-033` (СВОБОДА 01G)
- `LT-036` (ГЕОМЕТРИЯ 01V), `LT-037` (ГЕОМЕТРИЯ 02V)

Эти же leaf_type НЕ ДОЛЖНЫ (SHALL NOT) иметь ни одной строки mirror_finish_option — переклассификация в «остеклённое» полностью замещает прежнюю доступность исполнений зеркала для этих конкретных моделей (согласуется с требованием «Тип полотна leaf_type»: «с зеркалом» присваивается тем и только тем leaf_type, у которых есть mirror_finish_option).

#### Scenario: Перечисленные модели классифицированы как остеклённые
- **WHEN** запрашивается leaf_type с одним из перечисленных кодов
- **THEN** его panel_type равен «остеклённое», и для него существуют строки glazing_option на все шесть видов остекления

#### Scenario: Перечисленные модели недоступны с зеркалом
- **WHEN** запрашивается leaf_type с одним из перечисленных кодов
- **THEN** для него не существует ни одной строки mirror_finish_option

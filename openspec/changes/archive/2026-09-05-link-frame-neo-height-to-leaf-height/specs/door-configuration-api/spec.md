## ADDED Requirements

### Requirement: Совместимость диапазона высоты короба «НЕО» с высотой полотна
Если в запросе расчёта стоимости для frame-компонента, чей frame_type имеет код FT-003 («НЕО»), выбрана liner_dimension_option оси «Высота» (диапазон [min_value, max_value], где отсутствующая граница означает открытую с этой стороны границу, а при отсутствующем max_value верхней границей считается value), система ДОЛЖНА (SHALL) проверить, что значение высоты полотна, выбранное клиентом для leaf-компонента той же конфигурации, находится внутри этого диапазона. Если высота полотна не выбрана клиентом, либо выбранный диапазон её не покрывает, эндпоинт ДОЛЖЕН (SHALL) отвечать ошибкой 400 и не выполнять расчёт. Для frame_type с другим кодом эта проверка не выполняется, даже если у него есть опции высоты.

#### Scenario: Высота полотна внутри диапазона короба «НЕО» — расчёт выполняется
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) попадает в диапазон [min_value, max_value] выбранной высоты короба с frame_type кодом FT-003
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки

#### Scenario: Высота полотна вне диапазона короба «НЕО» — 400
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) не попадает в диапазон [min_value, max_value] выбранной высоты короба с frame_type кодом FT-003
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Высота короба «НЕО» выбрана без высоты полотна — 400
- **WHEN** отправляется запрос расчёта стоимости, в котором для frame-компонента с frame_type кодом FT-003 выбрана liner_dimension_option оси «Высота», а для leaf-компонента высота не выбрана
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Высота полотна в разрыве между диапазонами короба «НЕО» — 400
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) не попадает ни в один из непересекающихся диапазонов, заданных для опций высоты короба с frame_type кодом FT-003, но выбрана одна из этих опций высоты
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Проверка не применяется к другим типам короба
- **WHEN** отправляется запрос расчёта стоимости, где для frame-компонента с frame_type кодом, отличным от FT-003, выбрана liner_dimension_option оси «Высота», независимо от выбранной высоты полотна
- **THEN** эндпоинт выполняет расчёт как обычно, без проверки диапазона высоты полотна для этого компонента

### Requirement: Обязательность высоты для короба «НЕО»
Если в запросе расчёта стоимости для frame-компонента, чей frame_type имеет код FT-003 («НЕО»), не передан id liner_dimension_option оси «Высота» (heightOptionId отсутствует), эндпоинт ДОЛЖЕН (SHALL) отвечать ошибкой 400 и не выполнять расчёт — высота для этого типа короба обязательна, а не опциональна, как для прочих типов короба. Это гарантирует, что для высоты полотна, не покрытой ни одним диапазоном короба «НЕО» (см. «Совместимость диапазона высоты короба «НЕО» с высотой полотна»), расчёт с этим коробом невозможен ни при каком запросе — в том числе при полном отсутствии выбранной высоты короба.

#### Scenario: Короб «НЕО» без выбранной высоты — 400
- **WHEN** отправляется запрос расчёта стоимости, где для frame-компонента с frame_type кодом FT-003 не передан heightOptionId
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт, независимо от того, выбрана ли высота полотна

#### Scenario: Другие типы короба не требуют обязательной высоты
- **WHEN** отправляется запрос расчёта стоимости, где для frame-компонента с frame_type кодом, отличным от FT-003, не передан heightOptionId
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки, связанной с отсутствием высоты

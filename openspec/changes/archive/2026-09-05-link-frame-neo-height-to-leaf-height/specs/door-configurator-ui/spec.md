## ADDED Requirements

### Requirement: Условное отображение высоты короба «НЕО» по высоте полотна
Группа кнопок «Высота» для frame-компонента, чей тип короба имеет код FT-003 («НЕО»), ДОЛЖНА (SHALL) оставаться скрытой, пока клиент не выбрал значение высоты для leaf-компонента выбранной конфигурации. После выбора высоты полотна группа «Высота» этого frame-компонента ДОЛЖНА (SHALL) показывать только те его опции высоты из каталога, чей диапазон [min_value, max_value] (или [min_value, value], если max_value не задан) покрывает выбранную высоту полотна; остальные шаги и группы опций продолжают отображаться по действующим правилам без изменений. Для frame-компонента с любым другим типом короба группа «Высота» отображается без этой фильтрации, как раньше.

#### Scenario: Высота полотна ещё не выбрана — группа высоты короба «НЕО» скрыта
- **WHEN** выбранная конфигурация содержит frame-компонент с типом короба FT-003 и допустимыми опциями высоты, но клиент ещё не выбрал высоту для leaf-компонента
- **THEN** группа кнопок «Высота» для этого frame-компонента не отображается

#### Scenario: После выбора высоты полотна показывается только совместимый диапазон
- **WHEN** клиент выбрал высоту полотна, и среди опций высоты frame-компонента с типом короба FT-003 есть диапазон, покрывающий эту высоту
- **THEN** группа «Высота» этого frame-компонента показывает только эту опцию (опции, чей диапазон эту высоту не покрывает, не показываются)

#### Scenario: Высота полотна в разрыве между диапазонами — группа высоты короба «НЕО» пуста
- **WHEN** клиент выбрал высоту полотна, которая не попадает ни в один из диапазонов опций высоты frame-компонента с типом короба FT-003
- **THEN** группа «Высота» этого frame-компонента не показывает ни одной опции

#### Scenario: Изменение высоты полотна сбрасывает выбор высоты короба «НЕО»
- **WHEN** клиент меняет ранее выбранную высоту полотна после того, как высота короба с типом FT-003 уже была выбрана
- **THEN** выбор высоты короба сбрасывается, а группа «Высота» этого frame-компонента пересчитывается по новой высоте полотна

#### Scenario: Другие типы короба не фильтруются по высоте полотна
- **WHEN** выбранная конфигурация содержит frame-компонент с типом короба, отличным от FT-003, и у него есть опции высоты
- **THEN** группа «Высота» этого frame-компонента показывает все его опции высоты независимо от выбранной высоты полотна, как и до этого изменения

### Requirement: Исключение короба «НЕО» из каскада при несовместимой высоте полотна
Если клиент уже выбрал высоту полотна для leaf-компонента, и ни один диапазон высоты короба «НЕО» (frame_type код FT-003) её не покрывает, тип короба «НЕО» ДОЛЖЕН (SHALL) быть исключён из списка доступных типов на шаге каскадного выбора короба. Если высота полотна ещё не выбрана, короб «НЕО» остаётся в списке доступных типов короба, как раньше. Это дополнение к требованию «Условное отображение высоты короба «НЕО» по высоте полотна», а не замена: даже если это исключение по какой-либо причине не сработало (например, из-за порядка действий клиента), совместимость по-прежнему проверяется на бэкенде при расчёте стоимости.

#### Scenario: Короб «НЕО» скрыт из списка при несовместимой высоте полотна
- **WHEN** клиент уже выбрал высоту полотна, которая не попадает ни в один диапазон высоты короба «НЕО»
- **THEN** «НЕО» не отображается среди доступных типов короба на шаге каскадного выбора короба

#### Scenario: Короб «НЕО» остаётся в списке, пока высота полотна не выбрана
- **WHEN** клиент ещё не выбрал высоту полотна
- **THEN** «НЕО» отображается среди доступных типов короба на шаге каскадного выбора короба, как и до этого изменения

#### Scenario: Короб «НЕО» возвращается в список при совместимой высоте полотна
- **WHEN** клиент выбрал высоту полотна, которая попадает в один из диапазонов короба «НЕО»
- **THEN** «НЕО» отображается среди доступных типов короба на шаге каскадного выбора короба

## ADDED Requirements

### Requirement: Совместимость диапазона длины добора «ТС» с высотой полотна
Если в запросе расчёта стоимости для frameExtensions-компонента, чей frame_extensions_type имеет код из набора кодов добора «ТС» (FET-004, FET-005, FET-006, FET-007), выбрана liner_dimension_option оси «Длина» (диапазон [min_value, max_value], где отсутствующая граница означает открытую с этой стороны границу, а при отсутствующем max_value верхней границей считается value), система ДОЛЖНА (SHALL) проверить, что значение высоты полотна, выбранное клиентом для leaf-компонента той же конфигурации, находится внутри этого диапазона. Если высота полотна не выбрана клиентом, либо выбранный диапазон её не покрывает, эндпоинт ДОЛЖЕН (SHALL) отвечать ошибкой 400 и не выполнять расчёт. Для frame_extensions_type с кодом вне этого набора (в том числе для добора «КОМПЛАНАР», FET-008–FET-013) эта проверка не выполняется, даже если у него есть опции длины.

#### Scenario: Высота полотна внутри диапазона длины добора «ТС» — расчёт выполняется
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) попадает в диапазон [min_value, max_value] выбранной длины добора «ТС» (frameExtensions с frame_extensions_type кодом из набора FET-004–FET-007)
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки

#### Scenario: Высота полотна вне диапазона длины добора «ТС» — 400
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) не попадает в диапазон [min_value, max_value] выбранной длины добора «ТС»
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Длина добора «ТС» выбрана без высоты полотна — 400
- **WHEN** отправляется запрос расчёта стоимости, в котором для frameExtensions-компонента с frame_extensions_type кодом из набора FET-004–FET-007 выбрана liner_dimension_option оси «Длина», а для leaf-компонента высота не выбрана
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Высота полотна в разрыве между диапазонами длины добора «ТС» — 400
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) не попадает ни в один из непересекающихся диапазонов, заданных для опций длины добора «ТС», но выбрана одна из этих опций длины
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Проверка не применяется к добору «КОМПЛАНАР» и другим компонентам
- **WHEN** отправляется запрос расчёта стоимости, где для frameExtensions-компонента с frame_extensions_type кодом вне набора (например, добор «КОМПЛАНАР», FET-008) выбрана liner_dimension_option оси «Длина», независимо от выбранной высоты полотна
- **THEN** эндпоинт выполняет расчёт как обычно, без проверки диапазона высоты полотна для этого компонента

### Requirement: Обязательность длины для добора «ТС»
Если в запросе расчёта стоимости для frameExtensions-компонента, чей frame_extensions_type имеет код из набора кодов добора «ТС» (FET-004, FET-005, FET-006, FET-007), не передан id liner_dimension_option оси «Длина» (lengthOptionId отсутствует), эндпоинт ДОЛЖЕН (SHALL) отвечать ошибкой 400 и не выполнять расчёт — длина для этих типов добора обязательна, а не опциональна, как для прочих компонентов. Это гарантирует, что для высоты полотна, не покрытой ни одним диапазоном длины добора «ТС» (см. «Совместимость диапазона длины добора «ТС» с высотой полотна»), расчёт с этим добором невозможен ни при каком запросе — в том числе при полном отсутствии выбранной длины.

#### Scenario: Добор «ТС» без выбранной длины — 400
- **WHEN** отправляется запрос расчёта стоимости, где для frameExtensions-компонента с frame_extensions_type кодом из набора FET-004–FET-007 не передан lengthOptionId
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт, независимо от того, выбрана ли высота полотна

#### Scenario: Добор «КОМПЛАНАР» не требует обязательной длины
- **WHEN** отправляется запрос расчёта стоимости, где для frameExtensions-компонента с frame_extensions_type кодом вне набора FET-004–FET-007 (например, добор «КОМПЛАНАР») не передан lengthOptionId
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки, связанной с отсутствием длины

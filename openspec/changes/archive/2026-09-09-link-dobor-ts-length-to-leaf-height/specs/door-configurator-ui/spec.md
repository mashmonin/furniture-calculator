## ADDED Requirements

### Requirement: Условное отображение длины добора «ТС» по высоте полотна
Группа кнопок «Длина» для frameExtensions-компонента, чей тип добора имеет код из набора кодов добора «ТС» (FET-004, FET-005, FET-006, FET-007), ДОЛЖНА (SHALL) оставаться скрытой, пока клиент не выбрал значение высоты для leaf-компонента выбранной конфигурации. После выбора высоты полотна группа «Длина» этого frameExtensions-компонента ДОЛЖНА (SHALL) показывать только те его опции длины из каталога, чей диапазон [min_value, max_value] (или [min_value, value], если max_value не задан) покрывает выбранную высоту полотна; остальные шаги и группы опций продолжают отображаться по действующим правилам без изменений. Для frameExtensions-компонента с типом добора вне этого набора (в том числе для добора «КОМПЛАНАР») группа «Длина» отображается без этой фильтрации, как раньше.

#### Scenario: Высота полотна ещё не выбрана — группа длины добора «ТС» скрыта
- **WHEN** выбранная конфигурация содержит frameExtensions-компонент с типом добора из набора FET-004–FET-007 и допустимыми опциями длины, но клиент ещё не выбрал высоту для leaf-компонента
- **THEN** группа кнопок «Длина» для этого frameExtensions-компонента не отображается

#### Scenario: После выбора высоты полотна показывается только совместимый диапазон длины
- **WHEN** клиент выбрал высоту полотна, и среди опций длины frameExtensions-компонента с типом добора из набора есть диапазон, покрывающий эту высоту
- **THEN** группа «Длина» этого frameExtensions-компонента показывает только эту опцию (опции, чей диапазон эту высоту не покрывает, не показываются)

#### Scenario: Высота полотна в разрыве между диапазонами — группа длины добора «ТС» пуста
- **WHEN** клиент выбрал высоту полотна, которая не попадает ни в один из диапазонов опций длины frameExtensions-компонента с типом добора из набора (например, 2600–2850 или 2900–2950)
- **THEN** группа «Длина» этого frameExtensions-компонента не показывает ни одной опции

#### Scenario: Изменение высоты полотна сбрасывает выбор длины добора «ТС»
- **WHEN** клиент меняет ранее выбранную высоту полотна после того, как длина добора «ТС» уже была выбрана
- **THEN** выбор длины этого frameExtensions-компонента сбрасывается, а группа «Длина» пересчитывается по новой высоте полотна

#### Scenario: Добор «КОМПЛАНАР» не фильтруется по высоте полотна
- **WHEN** выбранная конфигурация содержит frameExtensions-компонент с типом добора вне набора FET-004–FET-007 (например, добор «КОМПЛАНАР»), и у него есть опции длины
- **THEN** группа «Длина» этого frameExtensions-компонента показывает все его опции длины независимо от выбранной высоты полотна, как и до этого изменения

### Requirement: Исключение добора «ТС» из каскада при несовместимой высоте полотна
Если клиент уже выбрал высоту полотна для leaf-компонента, и ни один диапазон длины типа добора из набора кодов добора «ТС» (FET-004, FET-005, FET-006, FET-007) её не покрывает, этот тип добора ДОЛЖЕН (SHALL) быть исключён из списка доступных типов на шаге каскадного выбора добора. Если высота полотна ещё не выбрана, типы добора из набора остаются в списке доступных типов, как раньше. Это дополнение к требованию «Условное отображение длины добора «ТС» по высоте полотна», а не замена: даже если это исключение по какой-либо причине не сработало, совместимость по-прежнему проверяется на бэкенде при расчёте стоимости.

#### Scenario: Тип добора «ТС» скрыт из списка при несовместимой высоте полотна
- **WHEN** клиент уже выбрал высоту полотна, которая не попадает ни в один диапазон длины типа добора из набора FET-004–FET-007
- **THEN** этот тип добора не отображается среди доступных типов на шаге каскадного выбора добора

#### Scenario: Тип добора «ТС» остаётся в списке, пока высота полотна не выбрана
- **WHEN** клиент ещё не выбрал высоту полотна
- **THEN** типы добора «ТС» отображаются среди доступных типов на шаге каскадного выбора добора, как и до этого изменения

#### Scenario: Тип добора «ТС» возвращается в список при совместимой высоте полотна
- **WHEN** клиент выбрал высоту полотна, которая попадает в один из диапазонов типа добора «ТС»
- **THEN** этот тип добора отображается среди доступных типов на шаге каскадного выбора добора

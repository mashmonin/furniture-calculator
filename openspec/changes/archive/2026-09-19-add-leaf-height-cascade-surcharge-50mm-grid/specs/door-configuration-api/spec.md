## MODIFIED Requirements

### Requirement: Разрешение произвольного значения размера полотна
Если для leaf-компонента указано произвольное значение длины или высоты, система ДОЛЖНА (SHALL) определить его статус в следующем порядке: (1) если значение совпадает с value одной из liner_dimension_option этого leaf_type для той же оси (стандартный каталожный размер) — считать наценку равной нулю, как при обычном выборе этой опции; (2) иначе искать применимую точную строку dimension_surcharge_rule для той же оси (liner_dimension_type) и этого значения — сперва специфичную для конкретного leaf_type этого компонента, при её отсутствии — общую (не привязанную к leaf_type); если найдена обычная строка — применить её surcharge_percent как наценку к цене leaf-компонента; если найдена блокирующая строка (unavailable = true) — считать значение недопустимым; (3) для оси высоты, если точной строки не нашлось (ни обычной, ни блокирующей), пробовать каскадное правило (см. dimension-surcharge-rules, «Каскадная наценка для промежуточных значений сетки 50мм высоты полотна»); (4) иначе — считать значение недопустимым.

#### Scenario: Значение совпадает со стандартным размером — наценки нет
- **WHEN** произвольное значение длины полотна совпадает со значением одной из его каталожных liner_dimension_option
- **THEN** расчёт выполняется без наценки за размер, как если бы клиент выбрал эту каталожную опцию

#### Scenario: Значение совпадает с правилом наценки — надбавка применяется
- **WHEN** произвольное значение длины или высоты полотна совпадает со значением общей строки dimension_surcharge_rule (не привязанной к конкретному leaf_type) для соответствующей оси
- **THEN** к retail_price и dealer_price найденной цены leaf-компонента применяется surcharge_percent этого правила

#### Scenario: Значение совпадает с правилом наценки конкретной модели — надбавка применяется
- **WHEN** произвольное значение длины или высоты полотна совпадает со значением dimension_surcharge_rule для соответствующей оси, привязанной к leaf_type этого компонента
- **THEN** к retail_price и dealer_price найденной цены leaf-компонента применяется surcharge_percent этого правила, а не общего правила с тем же значением (если оно существует)

#### Scenario: Значение высоты вычисляется каскадным правилом — надбавка применяется
- **WHEN** произвольное значение высоты полотна не совпадает ни с одним каталожным размером, ни с одной точной строкой dimension_surcharge_rule, но применимо каскадное правило (см. dimension-surcharge-rules)
- **THEN** к retail_price и dealer_price найденной цены leaf-компонента применяется наценка, вычисленная каскадным правилом

#### Scenario: Неизвестное значение отклоняется
- **WHEN** произвольное значение длины или высоты полотна не совпадает ни с одним каталожным размером этого leaf_type, ни с одной применимой строкой dimension_surcharge_rule для соответствующей оси (ни общей, ни специфичной для этого leaf_type), и для оси высоты каскадное правило тоже не даёт результата (значение вне сетки 50мм, ниже 1900мм, либо спуск по сетке упирается в блокирующую строку)
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

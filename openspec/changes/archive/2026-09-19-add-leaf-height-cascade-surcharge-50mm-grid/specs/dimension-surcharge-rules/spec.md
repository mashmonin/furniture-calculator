## MODIFIED Requirements

### Requirement: Структура dimension_surcharge_rule
Dimension_surcharge_rule ДОЛЖЕН (SHALL) ссылаться ровно на один liner_dimension_type; value обязателен. Строка задаётся ровно одним из двух взаимоисключающих способов: **обычное правило** — задан surcharge_percent (наценка применяется к этому значению); **блокирующее правило** — `unavailable = true`, surcharge_percent не задан (NULL); значение считается явно недопустимым для владельца этой строки, независимо от того, что могло бы быть вычислено по любому другому правилу (например, каскадному, см. «Каскадная наценка для промежуточных значений сетки 50мм высоты полотна»). Блокирующее правило ДОЛЖНО (SHALL) быть привязано к конкретному leaf_type (глобальная блокировка без владельца не допускается). Комбинация liner_dimension_type, value и владельца (leaf_type или его отсутствие) ДОЛЖНА (SHALL) быть уникальной.

#### Scenario: Правило требует liner_dimension_type, value и surcharge_percent
- **WHEN** строка dimension_surcharge_rule вставляется без ссылки на liner_dimension_type или без value, либо как обычное правило (unavailable не установлен) без surcharge_percent
- **THEN** база данных отклоняет вставку

#### Scenario: Значение не может повторяться для одного типа размера
- **WHEN** для одного и того же liner_dimension_type и одного и того же владельца (leaf_type или его отсутствие) вставляется вторая строка dimension_surcharge_rule с уже существующим value
- **THEN** база данных отклоняет вставку

#### Scenario: Для одного типа размера может быть несколько правил с разными значениями
- **WHEN** для одного liner_dimension_type вставляются несколько строк dimension_surcharge_rule с разными value и разными surcharge_percent
- **THEN** все строки сохраняются

#### Scenario: Правило не может быть одновременно обычным и блокирующим
- **WHEN** строка dimension_surcharge_rule вставляется с одновременно заданным surcharge_percent и unavailable = true
- **THEN** база данных отклоняет вставку

#### Scenario: Блокирующее правило требует привязки к конкретной модели полотна
- **WHEN** строка dimension_surcharge_rule вставляется с unavailable = true и без ссылки на leaf_type
- **THEN** база данных отклоняет вставку

### Requirement: Наценка за высоту полотна 2800/2900 мм, кроме модели «СИБИРЬ 03»
Для оси высоты (liner_dimension_type с кодом «ВЫСОТА») значения 2800 мм и 2900 мм ДОЛЖНЫ (SHALL) иметь dimension_surcharge_rule с surcharge_percent = 80, привязанную к каждой модели полотна (leaf_type) по отдельности, кроме модели «СИБИРЬ 03» — для неё вместо этого ДОЛЖНА (SHALL) существовать блокирующая строка (unavailable = true) с тем же value, явно помечающая эти значения как недопустимые для этой модели (а не просто отсутствие строки — см. «Структура dimension_surcharge_rule»), чтобы каскадное правило (см. «Каскадная наценка для промежуточных значений сетки 50мм высоты полотна») не могло случайно вычислить для них наценку через соседнее меньшее значение.

#### Scenario: Высота 2800 или 2900 мм доступна с наценкой 80% для любой модели, кроме «СИБИРЬ 03»
- **WHEN** для leaf-компонента с моделью, отличной от «СИБИРЬ 03», указано произвольное значение высоты 2800 мм или 2900 мм
- **THEN** значение принимается, к цене leaf-компонента применяется наценка 80%

#### Scenario: Высота 2800 или 2900 мм недоступна для модели «СИБИРЬ 03»
- **WHEN** для leaf-компонента с моделью «СИБИРЬ 03» указано произвольное значение высоты 2800 мм или 2900 мм
- **THEN** запрос отклоняется как недопустимое значение размера — из-за явной блокирующей строки, а не из-за отсутствия строки

## ADDED Requirements

### Requirement: Каскадная наценка для промежуточных значений сетки 50мм высоты полотна
Для оси высоты (liner_dimension_type с кодом «ВЫСОТА») значение размера, для которого нет ни каталожного соответствия, ни точного (обычного или блокирующего) правила dimension_surcharge_rule этого владельца, но которое лежит на сетке с шагом 50мм от 1900мм (`value = 1900 + 50×n`, n — целое ≥ 0), ДОЛЖНО (SHALL) считаться нестандартным со следующей наценкой: наценка ближайшего меньшего значения этой же сетки, для которого у этого владельца (leaf_type-специфичное правило либо, при его отсутствии, общее) есть точное обычное правило или которое само вычисляется этим же каскадным способом, увеличенная на 20 процентных пунктов за каждый пройденный шаг сетки. Если при спуске по сетке встречается блокирующая строка (unavailable = true) этого владельца — значение ДОЛЖНО (SHALL) считаться недопустимым, дальнейший спуск не выполняется. Значения ниже 1900мм и значения не на этой сетке (шаг ≠ 50мм от 1900) этим правилом не покрываются и обрабатываются как раньше (недопустимы, если для них нет ни каталожного размера, ни точного правила).

#### Scenario: Промежуточное значение через один шаг наследует наценку соседа
- **WHEN** для leaf-компонента указано произвольное значение высоты 2250 мм (сетка 50мм от 1900, нет точного правила ни для одной модели) и ближайшее меньшее значение сетки с точным правилом — 2200мм с наценкой 20%
- **THEN** значение принимается, к цене leaf-компонента применяется наценка 40% (20% + 20 процентных пунктов)

#### Scenario: Каскад продолжается через несколько подряд идущих промежуточных значений
- **WHEN** для leaf-компонента указано произвольное значение высоты 3000 мм, а 2950мм и 2900мм для этой модели полотна тоже не имеют собственных точных правил, но 2900мм каскадно наследует наценку от заведённого значения с наценкой 80%
- **THEN** значение принимается, наценка вычисляется последовательным наращиванием на 20 процентных пунктов за каждый пройденный шаг от последнего заведённого значения до 3000мм

#### Scenario: Каскад останавливается на блокирующей строке
- **WHEN** для leaf-компонента с моделью «СИБИРЬ 03» указано произвольное значение высоты 2850 мм (промежуточное значение сетки), и при спуске по сетке для этой модели встречается блокирующая строка на 2800мм
- **THEN** значение 2850 мм отклоняется как недопустимое, наценка не вычисляется через более раннее меньшее значение (2700мм)

#### Scenario: Промежуточное значение до блокирующей строки остаётся доступным
- **WHEN** для leaf-компонента с моделью «СИБИРЬ 03» указано произвольное значение высоты 2750 мм, а ближайшее меньшее заведённое значение сетки для этой модели — 2700мм с наценкой 50% (блокирующая строка на 2800мм при спуске от 2750мм не достигается)
- **THEN** значение принимается, к цене leaf-компонента применяется наценка 70% (50% + 20 процентных пунктов)

#### Scenario: Значение ниже 1900мм по-прежнему отклоняется
- **WHEN** для leaf-компонента указано произвольное значение высоты меньше 1900мм, не совпадающее ни с одним каталожным размером
- **THEN** запрос отклоняется как недопустимое значение размера, каскадное правило не применяется

#### Scenario: Значение не на сетке 50мм по-прежнему отклоняется
- **WHEN** для leaf-компонента указано произвольное значение высоты, не кратное 50мм от 1900мм (например, 2013мм), не совпадающее ни с одним каталожным размером и ни с одним точным правилом
- **THEN** запрос отклоняется как недопустимое значение размера, каскадное правило не применяется

## Context

См. proposal.md — Why. Денежные суммы сейчас форматируются в шести разных местах фронтенда (`ConfiguratorScreen.tsx`, `ComponentBreakdownList.tsx`, `CartScreen.tsx`) вручную — либо шаблонной строкой `` `${value} ₽` ``, либо через `suffix="₽"` у `antd Statistic` — без разделителя разрядов. Значения всегда приходят с backend уже целыми рублями (`DoorConfigurationPricingService` округляет `setScale(0, RoundingMode.HALF_UP)`), дробная часть на фронтенде никогда не появляется.

## Goals / Non-Goals

**Goals:**
- Единая точка форматирования денежной суммы, переиспользуемая всеми местами вывода цены.
- Формат: целое число, группы разрядов по 3 через обычный пробел, без символа валюты.

**Non-Goals:**
- Не меняются сами числовые значения, расчёты, округление или backend API.
- Не меняется формат чисел в выгружаемом `.xlsx` (там уже есть свои заголовки колонок с «₽», это отдельная, не затронутая этим изменением область — see order-export-api/door-configuration-export).
- Не вводится поддержка дробных/копеечных сумм — значения всегда целые.

## Decisions

- **Общая функция `formatMoney(value: number): string`** в новом (или существующем — на усмотрение реализации, например `frontend/src/format.ts`) модуле-утилите, использующая `new Intl.NumberFormat('ru-RU').format(value)`. Locale `ru-RU` даёт группировку по тысячам обычным пробелом и не добавляет валютный символ (в отличие от `Intl.NumberFormat` со `style: 'currency'`, который добавил бы «₽» — намеренно не используется).
  - Альтернатива: ручная регулярка/`replace` для расстановки пробелов — отклонено, `Intl.NumberFormat` — стандартный, локализованный и уже широко поддерживаемый способ, не требующий поддержки самодельной логики группировки.
- Все существующие места вывода суммы (`${value} ₽`, `suffix="₽"` у `Statistic`) заменяются вызовом `formatMoney(value)` без суффикса `₽`. У `antd Statistic` формат достигается через проп `formatter={(value) => formatMoney(Number(value))}` (без `suffix`).

## Risks / Trade-offs

- [Пропущенное место вывода суммы осталось со старым форматом] → Проверка всех текущих мест через `grep -rn "₽" frontend/src` до и после правки (список уже известен: `ConfiguratorScreen.tsx`, `ComponentBreakdownList.tsx`, `CartScreen.tsx`) — после изменения совпадений остаться не должно.
- [Значение внезапно окажется дробным] → Не ожидается (backend всегда возвращает целые рубли), но `Intl.NumberFormat` по умолчанию корректно обработает и дробное значение — поведение не является хрупким, даже если ожидание не выполнится.

## Why

Для полотна коллекций «Вертикаль», «Атмосфера», «Элегант», «Гармония», «Свобода», «Геометрия» и «Сияние» справочник цветов ограничен конкретными заведёнными вариантами. Фабрика может изготовить полотно в произвольном цвете из палитры RAL/NCS, не входящем в стандартный список, но такой заказ стоит дороже. Сейчас в справочнике нет позиции для этого случая и в расчёте стоимости нет соответствующей наценки.

## What Changes

- Добавить в справочник цветов новую позицию «Другой цвет из коллекции RAL и NCS», доступную для полотна коллекций Вертикаль, Атмосфера, Элегант, Гармония, Свобода, Геометрия и Сияние (коллекции Сибирь и Фантом не затрагиваются).
- Добавить процент наценки к цене полотна (surcharge_percent) как атрибут colour_type — по аналогии с mirror_finish_type и glazing_type. Для всех существующих цветов наценка равна 0%, для новой позиции — 20%.
- При расчёте стоимости, если для leaf-компонента выбран цвет «Другой цвет из коллекции RAL и NCS», применять наценку 20% к цене полотна последовательно с уже существующими наценками (длина, высота, зеркало, остекление, реверс).
- Включить проценты наценки по цветам в эндпоинт `GET /api/pricing-surcharges`, чтобы фронтенд мог показать наценку в разбивке «Надбавки к цене за нестандарт» без пересчёта из итоговой цены.
- На фронтенде показывать наценку за выбранный цвет в этом же блоке, если она ненулевая (аналогично тому, как уже показывается наценка за исполнение зеркала и за вид остекления).

## Capabilities

### Modified Capabilities
- `door-configuration-catalog`: добавляется структура colour_type (наименование, код, наценка к цене полотна) и конкретная новая позиция справочника «Другой цвет из коллекции RAL и NCS» с её доступностью по коллекциям.
- `door-configuration-api`: добавляется наценка за выбранный цвет полотна при расчёте стоимости, её место в последовательности применения наценок, и её отражение в ответе эндпоинта процентов надбавок.
- `door-configurator-ui`: разбивка надбавок к цене полотна дополняется строкой за наценку по цвету; список загружаемых при открытии страницы процентов надбавок дополняется процентами по цветам.

## Impact

- Backend: `ColourType` (новое поле `surchargePercent`), новая Liquibase-миграция на добавление столбца `colour_type.surcharge_percent` и миграция сид-данных (новая строка colour_type + строки colour_option для leaf_type коллекций LC-001–LC-007), `DoorConfigurationPricingService` (новый шаг наценки в последовательности применения наценок к цене полотна), `PricingSurchargesDto`/новый `ColourSurchargeDto`, сервис, отдающий `GET /api/pricing-surcharges`.
- Frontend: `PricingSurchargesDto` (TS-тип), `computeSurchargeBreakdown` в `App.tsx` — новый источник наценки за цвет в разбивке «Надбавки к цене за нестандарт».

## ADDED Requirements

### Requirement: Краткие наименования наличников «Компланар Реверс»
Для строк `door_casing_type` со следующими `code` ДОЛЖНО (SHALL) быть задано указанное краткое наименование:
- `DCT-005` («Авеню для системы КОМПЛАНАР РЕВЕРС \*») → «Авеню»
- `DCT-007` («Аура для системы КОМПЛАНАР РЕВЕРС \*») → «Аура»
- `DCT-009` («Ария для системы КОМПЛАНАР РЕВЕРС \*») → «Ария»

Для остальных строк `door_casing_type` (включая неревeрсивные «Авеню», «Аура», «Ария») краткое наименование не задаётся этим изменением.

#### Scenario: Краткие наименования наличников КОМПЛАНАР РЕВЕРС возвращаются в каталоге
- **WHEN** запрашивается каталог конфигураций или иной ответ API, включающий `door_casing_type` с кодом `DCT-005`, `DCT-007` или `DCT-009`
- **THEN** в ответе `shortName` этой строки равен «Авеню», «Аура» или «Ария» соответственно

#### Scenario: Неревeрсивные тёзки не получают краткое наименование этим изменением
- **WHEN** запрашивается ответ API, включающий `door_casing_type` «Авеню», «Аура» или «Ария» (без суффикса «для системы КОМПЛАНАР РЕВЕРС \*»)
- **THEN** `shortName` этой строки остаётся `null`

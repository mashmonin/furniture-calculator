## MODIFIED Requirements

### Requirement: Отображение позиций короба
Если выбранная конфигурация содержит frame-компонент, для которого каталог отдаёт непустой список его позиций frame_post, система ДОЛЖНА (SHALL) отобразить этот список внутри карточки компонента «Короб» — для каждой позиции название её post_type, quantity, length (если задана) и retail_price/dealer_price — за одним исключением: для позиции с post_type «Комплект зарезных стоек» length НЕ ДОЛЖНА (SHALL NOT) показываться, даже если задана в каталоге, поскольку это значение описывает длину одной стойки внутри комплекта, а не комплекта целиком, и его показ рядом с quantity вводит в заблуждение. Название, quantity и (кроме указанного исключения) length ДОЛЖНЫ (SHALL) показываться слева в строке позиции, а retail_price/dealer_price — справа в той же строке. Этот список — только для отображения: ни одна его позиция не выбирается пользователем и не входит в запрос расчёта стоимости.

#### Scenario: Короб с несколькими позициями показывает их все
- **WHEN** выбранная конфигурация содержит frame-компонент, чей список позиций frame_post из каталога содержит две записи
- **THEN** карточка «Короб» показывает обе позиции с их названием, количеством, длиной (если задана и это не «Комплект зарезных стоек») слева и ценой справа

#### Scenario: Короб без позиций не показывает список
- **WHEN** выбранная конфигурация содержит frame-компонент, чей список позиций frame_post из каталога пуст
- **THEN** карточка «Короб» не показывает список позиций, как и раньше

#### Scenario: Позиция «Комплект зарезных стоек» не показывает длину
- **WHEN** список позиций frame_post содержит позицию с post_type «Комплект зарезных стоек», для которой в каталоге задана длина
- **THEN** в строке этой позиции показываются название и количество (например, «Комплект зарезных стоек × 2»), но не длина

#### Scenario: Прочие позиции по-прежнему показывают длину
- **WHEN** список позиций frame_post содержит позицию с post_type, отличным от «Комплект зарезных стоек», для которой в каталоге задана длина
- **THEN** в строке этой позиции длина показывается, как и раньше

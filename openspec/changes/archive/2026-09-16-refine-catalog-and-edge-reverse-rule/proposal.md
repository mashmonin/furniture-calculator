## Why

Три независимых уточнения каталога, запрошенных вместе: (1) отображение позиции короба «Комплект зарезных стоек» вводит в заблуждение, показывая длину одной стойки так, будто это длина всего комплекта; (2) три наличника КОМПЛАНАР РЕВЕРС не имеют краткого наименования для компактных мест интерфейса; (3) сейчас обе кромки (прямая и с четвертью) доступны при любом открывании двери, хотя по факту прямая кромка совместима только с прямым открыванием, а кромка с четвертью — только с обратным (реверс).

## What Changes

- Позиция короба «Комплект зарезных стоек» в карточке «Короб» перестаёт показывать длину (сейчас — «Комплект зарезных стоек × 2, длина 2170») — становится «Комплект зарезных стоек × 2». Длина хранится в каталоге как есть; на фронте только скрывается для этой конкретной позиции, поскольку описывает одну стойку внутри комплекта, а не комплект целиком, и рядом с «× 2» вводит в заблуждение. Остальные позиции короба (например, «Стойка незарезная») по-прежнему показывают длину, если она задана.
- Наличникам КОМПЛАНАР РЕВЕРС задаётся краткое наименование: «Авеню для системы КОМПЛАНАР РЕВЕРС \*» → «Авеню», «Аура для системы КОМПЛАНАР РЕВЕРС \*» → «Аура», «Ария для системы КОМПЛАНАР РЕВЕРС \*» → «Ария». Их неревeрсивные тёзки («Авеню», «Аура», «Ария») и прочие наличники этим изменением краткого наименования не получают.
- Из каталога `door_configuration` удаляются строки, нарушающие новое соответствие вида кромки и признака реверса: прямая кромка (ET-001) больше не сочетается с `is_reverse = true`, кромка с четвертью (ET-002) больше не сочетается с `is_reverse = false`. Сейчас обе кромки симметрично доступны для обеих сторон реверса (см. design.md) — после этого изменения при обычном открывании доступна только прямая кромка, при реверсивном — только с четвертью. Это чистая правка данных каталога (новый Liquibase changeset) — ни backend-код, ни frontend-каскад не меняются: они уже показывают только то, что есть в каталоге.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `door-configurator-ui`: отображение позиции короба «Комплект зарезных стоек» больше не включает длину.
- `catalog-reference-short-name`: заданы краткие наименования для трёх наличников КОМПЛАНАР РЕВЕРС.
- `door-configuration-catalog`: добавлено правило соответствия вида кромки (edge_type) и признака реверса (is_reverse) — прямая кромка только для обычных конфигураций, кромка с четвертью только для реверсивных.

## Impact

- **Frontend**: `frontend/src/App.tsx` (отображение позиций короба — убрать длину для конкретного post_type).
- **Backend / данные**: новый Liquibase changeset, заполняющий `door_casing_type.short_name` для DCT-005/007/009; новый Liquibase changeset, удаляющий из `door_configuration` строки с несовместимой парой (edge_type, is_reverse). Backend-код и API-контракты не меняются.
- **Каталог**: пользователи, ранее выбиравшие прямую кромку при реверсе (или кромку с четвертью при обычном открывании), в существующих сохранённых расчётах не пострадают (расчёт стоимости не хранит состояние на сервере) — при следующем открытии калькулятора для реверсивной конфигурации будет предложена только кромка с четвертью, и наоборот.

## ADDED Requirements

### Requirement: Коллекции «Эмаль Лайт»
В справочнике collection ДОЛЖНЫ (SHALL) существовать коллекции MONO (`LC-010`), QUADRO (`LC-011`), VENEZIA (`LC-012`) и REFLEX (`LC-013`).

#### Scenario: Коллекции заведены
- **WHEN** запрашиваются коллекции после применения миграций
- **THEN** присутствуют коллекции MONO, QUADRO, VENEZIA и REFLEX с кодами `LC-010`…`LC-013`

### Requirement: Признак допустимости нестандартных размеров коллекции
Collection ДОЛЖНА (SHALL) иметь обязательный булев признак `custom_dimensions_allowed` — допускает ли коллекция произвольные (нестандартные) значения длины и высоты полотна помимо стандартных каталожных; по умолчанию `true` (все существующие коллекции сохраняют прежнее поведение). Для коллекций MONO, QUADRO, VENEZIA и REFLEX признак ДОЛЖЕН (SHALL) быть `false`.

#### Scenario: Признак обязателен
- **WHEN** строка collection вставляется без значения признака
- **THEN** используется значение по умолчанию `true`, а явная вставка NULL отклоняется базой данных

#### Scenario: Новые коллекции запрещают нестандартные размеры
- **WHEN** запрашиваются коллекции MONO, QUADRO, VENEZIA и REFLEX
- **THEN** у каждой признак `custom_dimensions_allowed` равен `false`

#### Scenario: Существующие коллекции разрешают нестандартные размеры
- **WHEN** запрашиваются коллекции `LC-001`…`LC-009`
- **THEN** у каждой признак `custom_dimensions_allowed` равен `true`

## MODIFIED Requirements

### Requirement: Произвольное значение длины и высоты полотна в запросе расчёта
Для leaf-компонента запрос расчёта стоимости ДОЛЖЕН (SHALL) допускать передачу произвольного значения длины и/или высоты в миллиметрах (customLengthValueMm/customHeightValueMm) вместо id каталожной liner_dimension_option (lengthOptionId/heightOptionId) для соответствующей оси. Для каждой оси (длина, высота) клиент МОЖЕТ (MAY) указать либо id каталожной опции, либо произвольное значение, но не оба одновременно. Произвольное значение высоты (customHeightValueMm, не длины) допустимо также для frame-компонента, чей frame_type имеет код из набора кодов коробов с высотой, зеркалирующей высоту полотна (на данный момент только FT-001 «Фантом», см. «Совпадение высоты короба «Фантом» с высотой полотна»); для всех прочих компонентов, отличных от leaf, и для длины любого компонента, отличного от leaf, произвольное значение по-прежнему недопустимо.

#### Scenario: Произвольное значение принимается вместо id опции
- **WHEN** отправляется запрос расчёта стоимости, где для leaf-компонента вместо lengthOptionId указано произвольное значение длины в мм
- **THEN** запрос обрабатывается, не возвращая ошибку валидации формата запроса

#### Scenario: Одновременное указание id опции и произвольного значения для одной оси недопустимо
- **WHEN** для одной и той же оси (например, длины) leaf-компонента одновременно указаны и lengthOptionId, и произвольное значение длины
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Произвольное значение для компонента, отличного от leaf, недопустимо
- **WHEN** произвольное значение длины или высоты указано для компонента, отличного от leaf, и отличного от frame-компонента с frame_type кодом из набора коробов с зеркалируемой высотой (например, для edge, doorCasing, frameExtensions, либо для короба «НЕО»/«Компланар»)
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Произвольное значение высоты допустимо для короба «Фантом»
- **WHEN** отправляется запрос расчёта стоимости, где для frame-компонента с frame_type кодом FT-001 указано произвольное значение высоты (customHeightValueMm)
- **THEN** запрос обрабатывается, не возвращая ошибку валидации формата запроса (совместимость этого значения с высотой полотна проверяется отдельным требованием «Совпадение высоты короба «Фантом» с высотой полотна»)

#### Scenario: Произвольное значение длины для короба «Фантом» недопустимо
- **WHEN** отправляется запрос расчёта стоимости, где для frame-компонента с frame_type кодом FT-001 указано произвольное значение длины (customLengthValueMm)
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт — у короба «Фантом» зеркалируется только высота, не длина

## ADDED Requirements

### Requirement: Совпадение высоты короба «Фантом» с высотой полотна
Если в запросе расчёта стоимости для frame-компонента, чей frame_type имеет код из набора кодов коробов с высотой, зеркалирующей высоту полотна (на данный момент только FT-001 «Фантом»), указано произвольное значение высоты (customHeightValueMm), система ДОЛЖНА (SHALL) проверить, что оно в точности равно значению высоты полотна, выбранному клиентом для leaf-компонента той же конфигурации (числовое равенство, а не диапазон, в отличие от коробов «НЕО»/«Компланар»). Если высота полотна не выбрана клиентом, либо указанное значение ей не равно, эндпоинт ДОЛЖЕН (SHALL) отвечать ошибкой 400 и не выполнять расчёт. Для frame_type с кодом вне этого набора эта проверка не выполняется. У короба «Фантом» нет каталожных liner_dimension_option оси «Высота» — customHeightValueMm единственный способ задать его высоту.

#### Scenario: Высота короба «Фантом» равна высоте полотна — расчёт выполняется
- **WHEN** отправляется запрос расчёта стоимости, где значение высоты полотна (leaf) в точности равно указанному произвольному значению высоты короба «Фантом» (FT-001)
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки

#### Scenario: Высота короба «Фантом» не равна высоте полотна — 400
- **WHEN** отправляется запрос расчёта стоимости, где указанное произвольное значение высоты короба «Фантом» отличается от значения высоты полотна той же конфигурации
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Высота короба «Фантом» указана без высоты полотна — 400
- **WHEN** отправляется запрос расчёта стоимости, где для frame-компонента с frame_type кодом FT-001 указано произвольное значение высоты, а для leaf-компонента высота не выбрана
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Проверка не применяется к другим коробам
- **WHEN** отправляется запрос расчёта стоимости, где для frame-компонента с frame_type кодом вне набора (например, FT-002 «Компланар» или FT-003 «НЕО») указана высота, независимо от значения высоты полотна
- **THEN** эта проверка на точное равенство не выполняется для этого компонента (совместимость таких коробов проверяется требованием «Совместимость диапазона высоты короба с высотой полотна»)

### Requirement: Обязательность высоты короба «Фантом»
Если в запросе расчёта стоимости для frame-компонента, чей frame_type имеет код из набора кодов коробов с высотой, зеркалирующей высоту полотна (FT-001), не указано customHeightValueMm, эндпоинт ДОЛЖЕН (SHALL) отвечать ошибкой 400 и не выполнять расчёт — высота для этого короба обязательна, а не опциональна. Поскольку у этого короба нет каталожных опций высоты, heightOptionId для него не может ссылаться на существующую строку (любое переданное значение отклоняется требованием «Опция не принадлежит компоненту конфигурации»); единственный способ задать высоту — обязательное customHeightValueMm.

#### Scenario: Короб «Фантом» без указанной высоты — 400
- **WHEN** отправляется запрос расчёта стоимости, где для frame-компонента с frame_type кодом FT-001 не указано ни heightOptionId, ни customHeightValueMm
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт, независимо от того, выбрана ли высота полотна

#### Scenario: Другие короба не требуют customHeightValueMm
- **WHEN** отправляется запрос расчёта стоимости, где для frame-компонента с frame_type кодом вне набора (FT-002, FT-003 или без опций высоты) не указано customHeightValueMm
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки, связанной с отсутствием customHeightValueMm — обязательность высоты для этих коробов регулируется другими требованиями

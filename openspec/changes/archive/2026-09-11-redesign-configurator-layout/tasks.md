## 5. Проверка

- [x] 5.1 `npm run build` и `npm run lint` во фронтенде проходят без ошибок.
- [x] 5.2 Ручная проверка в браузере: три колонки отображаются корректно на десктопном разрешении; аккордеон разворачивается/сворачивается независимо; изменение любой опции (полотно, короб, наличник, добор, фурнитура) вызывает автоматический пересчёт без клика; быстрые последовательные изменения не приводят к морганию пустой панели и не показывают устаревший результат; ошибка расчёта (например, эмуляция сетевого сбоя) отображается в sticky-панели. Подтверждено пользователем.
- [x] 5.3 Прогнать `openspec validate --strict` для изменения перед архивированием.

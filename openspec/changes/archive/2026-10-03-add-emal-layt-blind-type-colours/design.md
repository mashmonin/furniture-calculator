## Context

Тип полотна — `leaf_type.panel_type` (`BLIND`/`GLAZED`); у шести моделей «Эмаль Лайт» он `BLIND` (миграция `0116`), зеркала и остекления у них нет. Шаг «Тип полотна» в конфигураторе (`resolvePanelTypeStep`) показывается только если среди кандидатов больше одного значения; при одном — скрыт, коллекции показываются сразу. Цвета полотна — `colour_type` (код, название, `surcharge_percent`) и `colour_option` (привязка к `leaf_type`); цена полотна подбирается по `configuration_price`, у «Эмаль Лайт» строки цены без привязки к цвету, поэтому подходят любому цвету; надбавка за цвет считается по `colour_type.surcharge_percent` (у стандартных цветов 0). Существующие цвета других коллекций — с кодами вида `RAL-9003` и названиями «Матовый …»; последний код общего ряда — `CT-032`. Переключатель «Двустороннее» показывается всегда, когда у полотна есть цвета, и добавляет процентную надбавку за двустороннюю покраску. Сервисы описаны в `services.ts` (ключ, название, код прайс-листа, `defaultThicknessMm`).

## Goals / Non-Goals

**Goals:**
- Закрепить тип «Глухое» и показывать его выбранным в «Эмаль Лайт»; добавить три цвета; скрыть «Двустороннее» в «Эмаль Лайт».

**Non-Goals:**
- Остекление, зеркало, толщина 59 мм, цвета для других компонентов, «Другой цвет из RAL и NCS», серверный запрет двусторонней покраски.

## Decisions

1. **Тип «Глухое» — без новой миграции.** Данные верны с `0116`; требование в спеке фиксирует инвариант, тест проверяет.
2. **Поведение интерфейса задаётся в описании сервиса.** В `ServiceDef` добавляются `fixedPanelType` (у «Эмаль Лайт» — `BLIND`) и `allowDoubleSided` (у «Эмаль Лайт» — `false`; по умолчанию — разрешено) и передаются в `ConfiguratorScreen` пропсами, по образцу `defaultThicknessMm`. Альтернатива — вывод из данных (например, «у всех кандидатов один тип → показать»): изменило бы поведение «Эмаль и шпон» и других сервисов.
3. **Кнопка типа полотна.** При `fixedPanelType` шаг «Тип полотна» отображается всегда с единственным вариантом, выбранным по умолчанию; значение выбора принудительно равно `fixedPanelType`, поэтому «Очистить» и смена каскада его не снимают, повторный клик не отменяет выбор. Коллекции показываются сразу (тип считается выбранным).
4. **Цвета.** Новые записи `colour_type`: `CT-033` «Кремовая» (NCS 1002-Y20R), `CT-034` «Серый вереск» (RAL 7047), `CT-035` «Белое облако» (RAL 9003), `surcharge_percent = 0`; по одной `colour_option` на каждую из шести моделей (18 строк). По требованию пользователя значения RAL/NCS в интерфейсе («Эмаль Лайт») не показываются: названия заведены без них, а сами значения сохранены только в комментарии миграции (отдельный changeset `0123` переименовал цвета, уже заведённые в `0122`, не редактируя применённый). Так значения не попадают ни в список цветов, ни в корзину, ни в выгрузку; альтернатива — скрывать скобки только на фронтенде — потребовала бы разбора названия и не убрала бы значения из корзины и выгрузки. Цены полотна не меняются: строки цены без привязки к цвету подходят любому цвету. Альтернатива — переиспользовать существующие `RAL-9003`/`RAL-7044` и т. п.: названия другие («Матовый Снежный»), и менять их у других коллекций нельзя.
5. **«Двустороннее» скрыто только в интерфейсе.** Серверного запрета не вводится: двусторонняя покраска — необязательная опция запроса, которую интерфейс «Эмаль Лайт» не передаёт; это отличается от нестандартных размеров, где без запрета цена просто не находилась.

## Risks / Trade-offs

- [Скрытый «Двустороннее» можно передать через API] → осознанно (UI-ограничение); при необходимости запрет добавляется отдельным изменением по образцу признака `custom_dimensions_allowed`.
- [Значения RAL/NCS не видны пользователю] → осознанно; при необходимости показать их в будущем нужно отдельное поле справочника.
- [Принудительный выбор «Глухое» влияет на загрузку позиции из корзины] → значение `BLIND` совпадает с типом самих моделей, поэтому загрузка корректна; проверить вручную.

## Migration Plan

Один Liquibase changeset с данными (INSERT), без изменения схемы. Откат — удаление добавленных `colour_option`, затем `colour_type`.

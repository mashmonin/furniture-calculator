## ADDED Requirements

### Requirement: Кнопка выгрузки спецификации
Sticky-панель результата расчёта (см. «Sticky-панель результата расчёта») ДОЛЖНА (SHALL) отображать кнопку «Скачать excel спецификацию» — по макету (узел `#6:397` в Figma-файле, см. `docs/README.md`): сплошная акцентная (primary) кнопка на всю ширину панели, без иконки, расположенная в самом низу панели результата — после разбивки по фурнитуре (см. «Отображение фурнитуры в результате расчёта»), а не рядом с кнопкой «Очистить». Кнопка ДОЛЖНА (SHALL) отображаться только тогда, когда объединённый результат расчёта уже показан (см. door-configuration-export delta, «Объединение результатов трёх этапов расчёта» — те же условия применимости, что и у самого результата). По нажатию система ДОЛЖНА (SHALL) отправить на `POST /api/specification/export` запрос, собранный из уже имеющегося в приложении состояния (те же id и опции, что уже отправляются тремя этапными эндпоинтами расчёта — полотно и кромка, короб и обрамление, фурнитура), и инициировать скачивание полученного файла браузером.

#### Scenario: Кнопка показана вместе с результатом
- **WHEN** объединённый результат расчёта стоимости показан в sticky-панели
- **THEN** под разбивкой по фурнитуре (или под разбивкой по компонентам, если фурнитура не выбрана) видна кнопка «Скачать excel спецификацию»

#### Scenario: Кнопка не показана без результата
- **WHEN** результат расчёта ещё не готов, показывает ошибку или тип полотна не определён
- **THEN** кнопка «Скачать excel спецификацию» не отображается

#### Scenario: Нажатие запускает скачивание файла
- **WHEN** пользователь нажимает кнопку «Скачать excel спецификацию»
- **THEN** отправляется запрос на `POST /api/specification/export` с текущими выбранными опциями (той же комбинацией id и значений, что уже используется тремя этапными запросами расчёта стоимости), и по успешному ответу браузер сохраняет полученный `.xlsx`-файл

#### Scenario: Ошибка выгрузки не ломает панель результата
- **WHEN** запрос выгрузки спецификации завершается ошибкой
- **THEN** система показывает сообщение об ошибке выгрузки, а уже показанный результат расчёта стоимости остаётся видимым без изменений

## MODIFIED Requirements

### Requirement: Структура glazing_type
Glazing_type ДОЛЖЕН (SHALL) хранить наименование вида остекления (name) и процент наценки к цене полотна (surcharge_percent); оба поля обязательны. Glazing_type — глобальный справочник, не привязанный к конкретному leaf_type или коллекции.

Glazing_type ДОЛЖЕН (SHALL) содержать ровно следующие шесть строк с указанными процентами наценки:
- «Прозрачное» — 0% (базовое остекление, замена которого на другой вид и порождает наценку; собственной наценки не несёт)
- «Прозрачное серое» — 5%
- «Прозрачное бронза» — 5%
- «Сатинированное» — 5%
- «Сатинированное серое» — 10%
- «Сатинированное бронзовое» — 10%

#### Scenario: Правило требует name
- **WHEN** строка glazing_type вставляется без name или без surcharge_percent (оба поля теперь обязательны — см. требование выше)
- **THEN** база данных отклоняет вставку

#### Scenario: Существуют шесть предустановленных видов остекления
- **WHEN** запрашивается справочник glazing_type
- **THEN** в нём присутствуют ровно шесть строк с процентами наценки: «Прозрачное» (0%), «Прозрачное серое» (5%), «Прозрачное бронза» (5%), «Сатинированное» (5%), «Сатинированное серое» (10%), «Сатинированное бронзовое» (10%)

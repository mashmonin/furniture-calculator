## ADDED Requirements

### Requirement: Краткие наименования доборов ТС и КОМПЛАНАР
Для строк `frame_extensions_type` со следующими `code` ДОЛЖНО (SHALL) быть задано указанное краткое наименование:
- `FET-004` («Добор ТС 100 мм») → «100»
- `FET-005` («Добор ТС 140 мм») → «140»
- `FET-006` («Добор ТС 190 мм») → «190»
- `FET-007` («Добор ТС 400 мм») → «400»
- `FET-008` («Добор КОМПЛАНАР 100 мм») → «100»
- `FET-009` («Добор КОМПЛАНАР 140 мм») → «140»
- `FET-010` («Добор КОМПЛАНАР 190 мм») → «190»
- `FET-011` («Добор КОМПЛАНАР 400 мм») → «400»
- `FET-012` («Добор КОМПЛАНАР 600 мм») → «600»
- `FET-013` («Добор КОМПЛАНАР 800 мм») → «800»

Для остальных строк `frame_extensions_type` (в частности, `FET-001`–`FET-003`) краткое наименование не задаётся этим изменением.

#### Scenario: Краткие наименования доборов возвращаются в каталоге
- **WHEN** запрашивается каталог конфигураций или иной ответ API, включающий `frame_extensions_type` с кодом из набора `FET-004`–`FET-013`
- **THEN** в ответе `shortName` этой строки равен числу миллиметров из её названия («100», «140», «190», «400», «600» или «800» — в зависимости от кода)

#### Scenario: Прочие доборы не получают краткое наименование
- **WHEN** запрашивается ответ API, включающий `frame_extensions_type` с кодом вне набора `FET-004`–`FET-013` (например, `FET-001`)
- **THEN** `shortName` этой строки остаётся `null`

## ADDED Requirements

### Requirement: Условное отображение длины наличников короба «Компланар» по высоте полотна
Группа кнопок «Длина» для doorCasing-компонента, чей тип наличника имеет код из набора кодов наличников короба «Компланар» — «Эво» (DCT-001), «Авеню» (DCT-002, DCT-005), «Ария» (DCT-008, DCT-009), «Аура» (DCT-006, DCT-007), включая реверс-варианты (DCT-005, DCT-007, DCT-009) — ДОЛЖНА (SHALL) оставаться скрытой, пока клиент не выбрал значение высоты для leaf-компонента выбранной конфигурации. После выбора высоты полотна группа «Длина» этого doorCasing-компонента ДОЛЖНА (SHALL) показывать только те его опции длины из каталога, чей диапазон [min_value, max_value] (или [min_value, value], если max_value не задан) покрывает выбранную высоту полотна; остальные шаги и группы опций продолжают отображаться по действующим правилам без изменений. Для doorCasing-компонента с типом наличника вне этого набора (в том числе для наличников «Модо»/«Онда») группа «Длина» отображается без этой фильтрации, как раньше.

#### Scenario: Высота полотна ещё не выбрана — группа длины наличника скрыта
- **WHEN** выбранная конфигурация содержит doorCasing-компонент с типом наличника из набора DCT-001, DCT-002, DCT-005, DCT-006, DCT-007, DCT-008, DCT-009 и допустимыми опциями длины, но клиент ещё не выбрал высоту для leaf-компонента
- **THEN** группа кнопок «Длина» для этого doorCasing-компонента не отображается

#### Scenario: После выбора высоты полотна показывается только совместимый диапазон длины
- **WHEN** клиент выбрал высоту полотна, и среди опций длины doorCasing-компонента с типом наличника из набора есть диапазон, покрывающий эту высоту
- **THEN** группа «Длина» этого doorCasing-компонента показывает только эту опцию (опции, чей диапазон эту высоту не покрывает, не показываются)

#### Scenario: Наличник «Эво» показывает свою опцию длины, а не опцию других наличников короба «Компланар» в том же диапазоне
- **WHEN** клиент выбрал высоту полотна из диапазона [2150, 2250]
- **THEN** группа «Длина» для doorCasing-компонента «Эво» показывает опцию 2400 мм, а для doorCasing-компонента «Авеню», «Ария» или «Аура» — опцию 2700 мм

#### Scenario: Высота полотна в разрыве между диапазонами — группа длины наличника пуста
- **WHEN** клиент выбрал высоту полотна, которая не попадает ни в один из диапазонов опций длины doorCasing-компонента с типом наличника из набора
- **THEN** группа «Длина» этого doorCasing-компонента не показывает ни одной опции

#### Scenario: Изменение высоты полотна сбрасывает выбор длины наличника
- **WHEN** клиент меняет ранее выбранную высоту полотна после того, как длина наличника короба «Компланар» уже была выбрана
- **THEN** выбор длины этого doorCasing-компонента сбрасывается, а группа «Длина» пересчитывается по новой высоте полотна

#### Scenario: Прочие наличники не фильтруются по высоте полотна
- **WHEN** выбранная конфигурация содержит doorCasing-компонент с типом наличника вне набора (например, «Модо» или «Онда»), и у него есть опции длины
- **THEN** группа «Длина» этого doorCasing-компонента показывает все его опции длины независимо от выбранной высоты полотна, как и до этого изменения

### Requirement: Исключение наличников короба «Компланар» из каскада при несовместимой высоте полотна
Если клиент уже выбрал высоту полотна для leaf-компонента, и ни один диапазон длины типа наличника из набора кодов наличников короба «Компланар» (DCT-001, DCT-002, DCT-005, DCT-006, DCT-007, DCT-008, DCT-009) её не покрывает, этот тип наличника ДОЛЖЕН (SHALL) быть исключён из списка доступных типов на шаге каскадного выбора наличника. Если высота полотна ещё не выбрана, типы наличника из набора остаются в списке доступных типов, как раньше. Это дополнение к требованию «Условное отображение длины наличников короба «Компланар» по высоте полотна», а не замена: даже если это исключение по какой-либо причине не сработало, совместимость по-прежнему проверяется на бэкенде при расчёте стоимости.

#### Scenario: Тип наличника скрыт из списка при несовместимой высоте полотна
- **WHEN** клиент уже выбрал высоту полотна, которая не попадает ни в один диапазон длины типа наличника из набора DCT-001, DCT-002, DCT-005, DCT-006, DCT-007, DCT-008, DCT-009
- **THEN** этот тип наличника не отображается среди доступных типов на шаге каскадного выбора наличника

#### Scenario: Наличник «Эво» остаётся доступным при высоте, недоступной для «Авеню»/«Ария»/«Аура»
- **WHEN** клиент выбрал высоту полотна из диапазона [2600, 2850] для реверсивной или обычной конфигурации короба «Компланар»
- **THEN** тип наличника «Эво» (обычный или реверс-вариант) отображается среди доступных типов на шаге каскадного выбора наличника, а «Авеню», «Ария» и «Аура» (включая их реверс-варианты) — нет

#### Scenario: Тип наличника остаётся в списке, пока высота полотна не выбрана
- **WHEN** клиент ещё не выбрал высоту полотна
- **THEN** типы наличника короба «Компланар» отображаются среди доступных типов на шаге каскадного выбора наличника, как и до этого изменения

#### Scenario: Тип наличника возвращается в список при совместимой высоте полотна
- **WHEN** клиент выбрал высоту полотна, которая попадает в один из диапазонов типа наличника короба «Компланар»
- **THEN** этот тип наличника отображается среди доступных типов на шаге каскадного выбора наличника

## ADDED Requirements

### Requirement: Совместимость диапазона длины наличников короба «Компланар» с высотой полотна
Если в запросе расчёта стоимости для doorCasing-компонента, чей door_casing_type имеет код из набора кодов наличников короба «Компланар» — «Эво» (DCT-001), «Авеню» (DCT-002, DCT-005), «Ария» (DCT-008, DCT-009), «Аура» (DCT-006, DCT-007), включая реверс-варианты (DCT-005, DCT-007, DCT-009) — выбрана liner_dimension_option оси «Длина» (диапазон [min_value, max_value], где отсутствующая граница означает открытую с этой стороны границу, а при отсутствующем max_value верхней границей считается value), система ДОЛЖНА (SHALL) проверить, что значение высоты полотна, выбранное клиентом для leaf-компонента той же конфигурации, находится внутри этого диапазона. Если высота полотна не выбрана клиентом, либо выбранный диапазон её не покрывает, эндпоинт ДОЛЖЕН (SHALL) отвечать ошибкой 400 и не выполнять расчёт. Для door_casing_type с кодом вне этого набора (в том числе для наличников «Модо»/«Онда», DCT-003, DCT-004) эта проверка не выполняется, даже если у него есть опции длины.

#### Scenario: Высота полотна внутри диапазона длины наличника — расчёт выполняется
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) попадает в диапазон [min_value, max_value] выбранной длины наличника (doorCasing с door_casing_type кодом из набора DCT-001, DCT-002, DCT-005, DCT-006, DCT-007, DCT-008, DCT-009)
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки

#### Scenario: Высота полотна вне диапазона длины наличника — 400
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) не попадает в диапазон [min_value, max_value] выбранной длины наличника «Эво», «Авеню», «Ария» или «Аура» (включая реверс-варианты)
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Длина наличника выбрана без высоты полотна — 400
- **WHEN** отправляется запрос расчёта стоимости, в котором для doorCasing-компонента с door_casing_type кодом из набора DCT-001, DCT-002, DCT-005, DCT-006, DCT-007, DCT-008, DCT-009 выбрана liner_dimension_option оси «Длина», а для leaf-компонента высота не выбрана
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Высота полотна в разрыве между диапазонами длины наличника — 400
- **WHEN** отправляется запрос расчёта стоимости, где выбранная высота полотна (leaf) не попадает ни в один из непересекающихся диапазонов, заданных для опций длины наличника «Эво», «Авеню», «Ария» или «Аура», но выбрана одна из этих опций длины
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Для наличника «Эво» и наличников «Авеню»/«Ария»/«Аура» в одном диапазоне высоты допустимы разные длины
- **WHEN** отправляются два запроса расчёта стоимости с одинаковой высотой полотна из диапазона [2150, 2250] — один с doorCasing «Эво» (DCT-001) и длиной 2400 мм, другой с doorCasing «Авеню», «Ария» или «Аура» и длиной 2700 мм
- **THEN** оба запроса выполняют расчёт как обычно, без ошибки — каждый со своей допустимой для этого наличника длиной

#### Scenario: Реверс-вариант наличника проверяется по тем же диапазонам, что и обычный
- **WHEN** отправляется запрос расчёта стоимости для реверсивной конфигурации с doorCasing-компонентом «Авеню для системы КОМПЛАНАР РЕВЕРС» (DCT-005), «Аура для системы КОМПЛАНАР РЕВЕРС» (DCT-007) или «Ария для системы КОМПЛАНАР РЕВЕРС» (DCT-009) и длиной, допустимой для этого диапазона высоты полотна
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки — реверс-вариант ограничен тем же диапазоном длины, что и соответствующий обычный наличник

#### Scenario: Проверка не применяется к другим наличникам и компонентам
- **WHEN** отправляется запрос расчёта стоимости, где для doorCasing-компонента с door_casing_type кодом вне набора (например, «Модо», DCT-003) выбрана liner_dimension_option оси «Длина», независимо от выбранной высоты полотна
- **THEN** эндпоинт выполняет расчёт как обычно, без проверки диапазона высоты полотна для этого компонента

### Requirement: Обязательность длины для наличников короба «Компланар»
Если в запросе расчёта стоимости для doorCasing-компонента, чей door_casing_type имеет код из набора кодов наличников короба «Компланар» (DCT-001, DCT-002, DCT-005, DCT-006, DCT-007, DCT-008, DCT-009), не передан id liner_dimension_option оси «Длина» (lengthOptionId отсутствует), эндпоинт ДОЛЖЕН (SHALL) отвечать ошибкой 400 и не выполнять расчёт — длина для этих наличников обязательна, а не опциональна, как для прочих наличников. Это гарантирует, что для высоты полотна, не покрытой ни одним диапазоном длины наличника (см. «Совместимость диапазона длины наличников короба «Компланар» с высотой полотна»), расчёт с таким наличником невозможен ни при каком запросе — в том числе при полном отсутствии выбранной длины.

#### Scenario: Наличник короба «Компланар» без выбранной длины — 400
- **WHEN** отправляется запрос расчёта стоимости, где для doorCasing-компонента с door_casing_type кодом из набора DCT-001, DCT-002, DCT-005, DCT-006, DCT-007, DCT-008, DCT-009 не передан lengthOptionId
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт, независимо от того, выбрана ли высота полотна

#### Scenario: Прочие наличники не требуют обязательной длины
- **WHEN** отправляется запрос расчёта стоимости, где для doorCasing-компонента с door_casing_type кодом вне этого набора (например, «Модо»/«Онда» или прочие наличники) не передан lengthOptionId
- **THEN** эндпоинт выполняет расчёт как обычно, без ошибки, связанной с отсутствием длины

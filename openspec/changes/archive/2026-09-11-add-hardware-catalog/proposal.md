## Why

Сейчас в приложении нет справочника фурнитуры (замки, цилиндры, петли, дополнительная фурнитура, крепление плинтуса, ручки для раздвижных дверей). Менеджеру нужно иметь возможность добавить к расчёту одной или нескольких единиц фурнитуры и получить итоговую стоимость двери с их учётом. Фурнитура не привязана к конкретной конфигурации двери и не участвует в существующих наценках — она добавляется к итогу расчёта после всех прочих вычислений, с учётом количества выбранных единиц.

## What Changes

- Новый справочник фурнитуры: категория (группа) → тип фурнитуры → цветовой вариант с ценами (дилер/розница). Пример категорий: «Замки, цилиндры», «Петли Италия», «Петли Armadillo», «Дополнительная фурнитура», «Крепление плинтуса», «Ручки для раздвижных дверей».
- Единый глобальный каталог фурнитуры без ограничений по типу/системе двери — доступен для любой конфигурации.
- Новый эндпоинт получения каталога фурнитуры (аналог существующих справочных эндпоинтов каталога).
- Расчёт стоимости (`POST /api/door-configurations/{id}/price`) расширяется независимым списком позиций фурнитуры: каждая позиция — цветовой вариант фурнитуры + количество единиц. Стоимость каждой позиции = цена варианта × количество; сумма по всем позициям добавляется к итоговым `totalDealerPrice`/`totalRetailPrice` после расчёта стоимости компонентов двери. Фурнитура не участвует в надбавках/наценках, применяемых к компонентам двери.
- Ответ расчёта дополняется разбивкой по позициям фурнитуры (аналогично разбивке по компонентам).
- UI конфигуратора дополняется блоком выбора фурнитуры: возможность добавить несколько позиций (категория → тип → цвет → количество), увидеть их в разбивке стоимости и итоге.
- Начальное наполнение справочника — данными, предоставленными пользователем (загружается через Liquibase changelog'и).

## Capabilities

### New Capabilities
- `hardware-catalog`: справочник фурнитуры (категории, типы, цветовые варианты с ценами) и API для его чтения.

### Modified Capabilities
- `door-configuration-api`: запрос расчёта стоимости принимает необязательный список позиций фурнитуры; ответ включает стоимость и разбивку по фурнитуре, а итоговые суммы учитывают её стоимость.
- `door-configurator-ui`: экран конфигуратора получает блок выбора фурнитуры (список позиций с количеством) и отображает её в результатах расчёта.

## Impact

- Backend: новые доменные сущности (`HardwareCategory`, `HardwareType`, `HardwareColourOption` или аналогичные), репозитории, `HardwareCatalogService`, `HardwareCatalogController`, новые Liquibase changelog'и (схема + начальные данные), расширение `PricingRequestDto`/`PricingResponseDto` и `DoorConfigurationPricingService`.
- Frontend: новый компонент выбора фурнитуры в конфигураторе, расширение запроса/ответа расчёта стоимости, отображение позиций фурнитуры в разбивке итога.
- База данных: новые таблицы под справочник фурнитуры, без изменения существующих таблиц `door_configuration`/`configuration_price` и т. п.

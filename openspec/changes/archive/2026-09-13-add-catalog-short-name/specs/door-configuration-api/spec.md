## MODIFIED Requirements

### Requirement: Исполнения зеркала в ответе эндпоинта процентов надбавок
Ответ эндпоинта получения процентов надбавок (`GET /api/pricing-surcharges`) ДОЛЖЕН (SHALL), в дополнение к существующим полям, содержать список всех исполнений зеркала (mirror_finish_type) с их id, наименованием, кратким наименованием (значение short_name, либо `null`, если оно не задано) и процентом наценки.

#### Scenario: Возвращаются все исполнения зеркала с процентами
- **WHEN** запрашивается эндпоинт получения процентов надбавок
- **THEN** ответ содержит все строки mirror_finish_type с их наименованием, кратким наименованием (или `null`) и процентом наценки, наряду с уже существующими полями (правила наценки за размер, процент надбавки за реверс)

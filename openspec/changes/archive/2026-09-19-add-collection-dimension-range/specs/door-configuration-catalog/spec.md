## ADDED Requirements

### Requirement: Диапазон допустимой нестандартной длины/высоты полотна в каталоге конфигураций
Для leaf-компонента каждой door_configuration в ответе каталога конфигураций система ДОЛЖНА (SHALL) включать список диапазонов допустимой нестандартной длины/высоты (по одной записи на ось размера, для которой у коллекции этого leaf_type задан collection_dimension_range, см. door-collection-catalog) — тип размера, минимальное и максимальное допустимое значение. Для осей, по которым collection_dimension_range для этой коллекции не задан, соответствующая запись в списке отсутствует. Для компонентов, отличных от leaf (frame, edge, doorCasing, frameExtensions), список диапазонов ДОЛЖЕН (SHALL) быть пустым.

#### Scenario: Полотно с заданным диапазоном коллекции показывает его в каталоге
- **WHEN** запрашивается каталог конфигураций и коллекция leaf_type данной door_configuration имеет collection_dimension_range для оси длины или высоты
- **THEN** в ответе для leaf-компонента этой конфигурации присутствует запись с этой осью, минимальным и максимальным значением

#### Scenario: Полотно без диапазона для конкретной оси не показывает запись для неё
- **WHEN** запрашивается каталог конфигураций и коллекция leaf_type данной door_configuration не имеет collection_dimension_range для какой-либо из осей (длина, высота)
- **THEN** в ответе для leaf-компонента этой конфигурации список диапазонов не содержит записи для этой оси, запрос не завершается ошибкой

#### Scenario: Остальные компоненты не имеют диапазонов размера
- **WHEN** запрашивается каталог конфигураций
- **THEN** для frame-, edge-, doorCasing- и frameExtensions-компонентов список диапазонов в ответе всегда пуст

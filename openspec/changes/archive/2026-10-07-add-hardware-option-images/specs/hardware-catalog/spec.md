## ADDED Requirements

### Requirement: Фото цветового варианта фурнитуры
Для каждого цветового варианта фурнитуры, чей артикул имеет фотографию в приложении, каталог фурнитуры ДОЛЖЕН (SHALL) возвращать ссылку на фото (`imageUrl`); для варианта без артикула или без фотографии ссылка ДОЛЖНА (SHALL) быть пустой (`null`), запрос не завершается ошибкой. Фото сопоставляется варианту по артикулу, а не по названию типа или цвета: у разных цветов одной модели фото независимы.

Система ДОЛЖНА (SHALL) предоставлять эндпоинт получения файла фото по ссылке из каталога; ответ ДОЛЖЕН (SHALL) содержать корректный тип содержимого изображения и разрешать кэширование на стороне клиента. Запрос несуществующего файла ДОЛЖЕН (SHALL) завершаться кодом 404; имя файла НЕ ДОЛЖНО (SHALL NOT) позволять выйти за пределы каталога фотографий.

#### Scenario: Вариант с фото
- **WHEN** запрашивается каталог фурнитуры и для артикула цветового варианта «SC-00269698» в приложении есть фото
- **THEN** у этого варианта в ответе заполнен `imageUrl`, а запрос по этой ссылке возвращает изображение с кодом 200

#### Scenario: Артикул со слэшем
- **WHEN** у цветового варианта артикул «FM 100-50 MSN/CP» и для него есть фото
- **THEN** `imageUrl` заполнен и ведёт на существующее фото этого варианта

#### Scenario: Вариант без фото
- **WHEN** у цветового варианта нет артикула или для артикула нет фото
- **THEN** `imageUrl` равен `null`, остальные поля варианта возвращаются как обычно

#### Scenario: Несуществующий файл
- **WHEN** запрашивается фото по имени, которого нет среди сохранённых
- **THEN** эндпоинт возвращает код 404

#### Scenario: Попытка выйти за каталог
- **WHEN** в имени запрашиваемого файла есть последовательности вроде «../»
- **THEN** файл не отдаётся, эндпоинт возвращает код 404 (или 400), содержимое вне каталога фотографий недоступно

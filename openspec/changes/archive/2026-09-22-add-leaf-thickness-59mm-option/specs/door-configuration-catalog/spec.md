## ADDED Requirements

### Requirement: Опция толщины полотна 59 мм по коллекциям
Для leaf_type коллекций Вертикаль, Атмосфера, Элегант, Гармония, Свобода, Геометрия, Сияние, Сибирь и Фантом, чей `panel_type` не равен «остеклённое», ДОЛЖНА (SHALL) существовать строка `liner_dimension_option` для оси «ТОЛЩИНА» со значением 59 и `is_standard = true` — толщина 59 мм доступна как опция наравне со стандартной толщиной 44 мм. Для leaf_type этих же коллекций с `panel_type = «остеклённое»` (модели …01V/02V/021V/01G) такая строка НЕ ДОЛЖНА (SHALL NOT) существовать — толщина 59 мм для остеклённых моделей не производится. Для leaf_type коллекций, не входящих в перечисленный список, опция толщины 59 мм не заводится этим требованием.

#### Scenario: Не остеклённая модель перечисленной коллекции получает опцию 59 мм
- **WHEN** запрашивается каталог допустимых размеров для leaf_type перечисленной коллекции, чей panel_type не равен «остеклённое»
- **THEN** среди опций толщины присутствует значение 59 мм, помеченное как стандартное (is_standard = true), наравне со значением 44 мм

#### Scenario: Остеклённая модель не получает опцию 59 мм
- **WHEN** запрашивается каталог допустимых размеров для leaf_type перечисленной коллекции, чей panel_type равен «остеклённое» (например, ЭЛЕГАНТ 01V)
- **THEN** среди опций толщины присутствует только значение 44 мм, значения 59 мм нет

#### Scenario: Коллекция вне списка не получает опцию 59 мм
- **WHEN** запрашивается каталог допустимых размеров для leaf_type коллекции, не входящей в перечисленный список
- **THEN** среди опций толщины присутствует только значение 44 мм, значения 59 мм нет

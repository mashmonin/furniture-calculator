## ADDED Requirements

### Requirement: Наценка за толщину полотна 59 мм
Для оси толщины (`liner_dimension_type` с кодом «ТОЛЩИНА») ДОЛЖНА (SHALL) существовать строка `dimension_surcharge_rule` со значением 59 мм и `surcharge_percent = 20`, не привязанная к конкретному `leaf_type` (общее правило). Выбор значения 59 мм клиентом возможен только через id каталожной `liner_dimension_option` этого leaf_type (у толщины нет режима произвольного значения, в отличие от длины и высоты) — поэтому общее (не специфичное для leaf_type) правило безопасно: наценка фактически применяется только к тем leaf_type, для которых заведена соответствующая каталожная опция толщины 59 мм (см. door-configuration-catalog, «Опция толщины полотна 59 мм по коллекциям»).

#### Scenario: Толщина 59 мм даёт наценку 20%
- **WHEN** для leaf-компонента выбрана каталожная опция толщины со значением 59 мм
- **THEN** к цене leaf-компонента применяется наценка 20%, определённая правилом dimension_surcharge_rule для оси «ТОЛЩИНА» и значения 59

#### Scenario: Толщина 44 мм не даёт наценки
- **WHEN** для leaf-компонента выбрана каталожная опция толщины со значением 44 мм, либо толщина не выбрана вовсе
- **THEN** наценка за толщину не применяется, цена leaf-компонента не изменяется этим правилом

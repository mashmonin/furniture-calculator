## ADDED Requirements

### Requirement: Наценка за выбранную толщину полотна
Если для leaf-компонента выбрана каталожная опция толщины (id `liner_dimension_option` для оси «ТОЛЩИНА»), для значения которой существует применимая строка `dimension_surcharge_rule` (сперва специфичная для leaf_type этого компонента, при её отсутствии — общая), система ДОЛЖНА (SHALL) применить её `surcharge_percent` как наценку к цене leaf-компонента. Если для значения выбранной опции толщины нет ни специфичной, ни общей строки `dimension_surcharge_rule` (в том числе для стандартной толщины 44 мм), либо толщина не выбрана вовсе, шаг наценки за толщину пропускается, не изменяя цену — это не считается ошибкой, в отличие от произвольного (нестандартного) значения длины/высоты: у толщины нет режима произвольного значения, выбор всегда идёт по id существующей каталожной опции, поэтому отсутствие правила наценки для неё означает лишь «наценки нет», а не «недопустимое значение».

#### Scenario: Выбрана толщина с наценкой
- **WHEN** отправляется запрос расчёта стоимости, в котором для leaf-компонента выбрана опция толщины, для значения которой есть dimension_surcharge_rule с surcharge_percent = 20
- **THEN** к цене leaf-компонента применяется наценка 20%

#### Scenario: Выбрана толщина без наценки
- **WHEN** отправляется запрос расчёта стоимости, в котором для leaf-компонента выбрана опция толщины, для значения которой нет ни одной строки dimension_surcharge_rule (например, стандартная толщина 44 мм)
- **THEN** цена leaf-компонента вычисляется без наценки за толщину, как и до появления этого требования

#### Scenario: Толщина не выбрана
- **WHEN** отправляется запрос расчёта стоимости, в котором для leaf-компонента толщина не указана
- **THEN** цена leaf-компонента вычисляется без шага наценки за толщину

### Requirement: Место наценки за толщину полотна в последовательности надбавок
Наценка за выбранную толщину полотна (см. «Наценка за выбранную толщину полотна») ДОЛЖНА (SHALL) применяться к цене leaf-компонента последовательно, вместе с уже существующими наценками (см. «Последовательное применение наценок к цене полотна», «Место наценки за цвет в последовательности надбавок», «Место надбавки за двустороннюю покраску в последовательности надбавок», «Место наценки за исполнение зеркала в последовательности надбавок», «Место наценки за вид остекления в последовательности надбавок»), в следующем порядке: (1) наценка за длину; (2) наценка за высоту; (3) наценка за толщину (если применяется); (4) наценка за цвет (если применяется); (5) надбавка за двустороннюю покраску (если применяется); (6) наценка за исполнение зеркала (если выбрано); (7) наценка за вид остекления (если выбран); (8) надбавка за реверс (если конфигурация реверсивная) — каждый шаг применяется к результату предыдущего, с округлением после каждого шага.

#### Scenario: Наценка за толщину применяется после высоты и до цвета
- **WHEN** отправляется запрос расчёта стоимости для реверсивной конфигурации, в котором для leaf-компонента указаны произвольное значение высоты, совпадающее с dimension_surcharge_rule, опция толщины с наценкой 20% и цвет с ненулевой наценкой
- **THEN** итоговая цена leaf-компонента вычисляется как: сумма₁ = округление(базовая_цена × (1 + наценка_за_высоту)); сумма₂ = округление(сумма₁ × (1 + 0.2)); сумма₃ = округление(сумма₂ × (1 + наценка_за_цвет)); итог = округление(сумма₃ × (1 + надбавка_за_реверс))

## Context

`CartScreen.tsx`: заголовок «Корзина заказа» и подзаголовок — в `header` (flex, space-between с кнопкой «Добавить новую конфигурацию»); панель выгрузки справа внизу — строка «Формат файла», затем «Выгрузить заказ» (`type="primary"`) и «Выгрузить КП» (обычная). Корзина мутируется в `App.tsx`; `CartScreen` всегда смонтирован (скрывается стилем `display`), поэтому локальное состояние сохраняется при переключении экранов. КП: `CommercialOfferService.PageHeader` рисует шапку страницы вручную (логотип, две строки с линиями по `y = высота − 100` и `−128`), `TOP_MARGIN = 150`. Эндпоинт принимает JSON-массив позиций. Название прайс-листа PL-003 в `App.tsx` кладут в `priceListNames` два независимых `useEffect`: первый вызывает `setPriceListNames(names)` — полная замена объекта.

## Goals / Non-Goals

**Goals:** все пункты из proposal; корректная вёрстка шапки КП с одной или двумя дополнительными строками.

**Non-Goals:** хранение текста поля в localStorage или в корзине; текст заказа в Excel; редактируемый адрес (адрес — константа); перенос длинного текста на несколько строк.

## Decisions

**1. Причина пропажи прайс-листа — гонка и замена объекта.** Каталог дверей большой (~8000 конфигураций) и отвечает позже каталога фурнитуры; его `setPriceListNames(names)` стирает уже сохранённое `PL-003`. Исправление — функциональное слияние `setPriceListNames((prev) => ({ ...prev, ...names }))` (второй эффект уже мержит). Альтернатива — вынести PL-003 в константу: хуже, название берётся из каталога.

**2. Текст заказа — параметр запроса `orderNote`, а не новое тело.** Тело `export-offer` остаётся массивом позиций (совместимость, общая валидация с `export-order`); `@RequestParam(required = false) String orderNote`. Альтернатива — объект `{orderNote, lines}`: ломает контракт и тесты ради одного поля. Текст ≤ 80 символов — безопасная длина URL; кириллица кодируется `URLSearchParams`/`encodeURIComponent`. Обрезка и trim — на backend (не доверяем клиенту).

**3. Состояние поля — `useState` в `CartScreen`** (не в localStorage): текст относится к конкретной выгрузке, а экран не размонтируется при переключении. Поле — `Input` из `antd` с `maxLength={80}` и `allowClear`, в `header` рядом с заголовком (заголовок слева, поле растягивается, кнопка «Добавить новую конфигурацию» остаётся справа).

**4. Кнопки.** Порядок: «Выгрузить КП» (`type="primary"`, `FilePdfOutlined`), затем «Выгрузить заказ» (по умолчанию, `DownloadOutlined`). Строка «Формат файла» удаляется целиком. Допущение: «поменять цвета» понято как обмен цветов вместе с обменом мест (синяя — КП, обычная — заказ).

**5. Шапка КП.** `PageHeader` получает `orderNote` и константы адреса и менеджера. Строки сверху вниз: [«Заказ»], «Номер», «Дата и время», «Адрес магазина», «Менеджер» — шаг 28 pt, у каждой линия-разделитель. Все строки рисует один метод `drawRow`: название — обычным приглушённым шрифтом слева, значение — полужирным справа в колонке `valueX`. Значение шире колонки сначала уменьшается до 8 pt, затем переносится на две строки (слово длиннее колонки режется по символам, остаток — «…»). Верхний отступ документа вычисляется по числу строк: `TOP_MARGIN + 28 × (2 строки без заказа, 3 с заказом)`, чтобы страница позиции не наезжала на шапку. Допущение: менеджер — константа по умолчанию (редактируемого поля в интерфейсе пока нет); название строки с адресом — «Адрес магазина». Альтернатива — постоянный максимальный отступ: лишняя пустота, если текст не задан.

**6. «Итого по заказу:»** — меняется только подпись итоговой строки КП (`totalTable`); Excel-выгрузка и экран корзины не затрагиваются.

## Risks / Trade-offs

- Верхний отступ растёт → на странице меньше места для таблицы комплектации; длинные комплектации чаще переносятся на следующую страницу → проверить вёрстку PDF визуально для одной и двух строк.
- Символы «» и «₽» в адресе — шрифт Roboto их содержит (проверить на выгрузке).
- Текст заказа не сохраняется между запусками — ожидаемо, зафиксировано в спеке.

## Migration Plan

Миграций БД нет; новый параметр необязательный, старые клиенты работают без изменений. Откат — возврат трёх групп правок (UI, параметр, шапка).

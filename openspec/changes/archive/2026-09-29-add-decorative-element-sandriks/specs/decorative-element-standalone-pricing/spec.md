## MODIFIED Requirements

### Requirement: Расчёт стоимости списка позиций декоративных элементов
Система ДОЛЖНА (SHALL) предоставлять эндпоинт расчёта стоимости, принимающий список позиций декоративных элементов — независимо от какой-либо `door_configuration` или полотна. Каждая позиция ДОЛЖНА (SHALL) указывать id существующего decorative_element_type и МОЖЕТ (MAY) указывать количество — положительное целое число единиц; отсутствие количества ДОЛЖНО (SHALL) трактоваться как 1. Список МОЖЕТ (MAY) содержать несколько позиций с одинаковым decorative_element_type — они не объединяются и учитываются как отдельные позиции. Правила расчёта стоимости каждой позиции (цена типа × количество) и обработки ошибок (несуществующий decorative_element_type, неположительное количество) те же, что и при учёте декоративных элементов в расчёте по `door_configuration` (см. door-configuration-api, «Учёт декоративных элементов в расчёте стоимости изделия»). Запрос ДОПОЛНИТЕЛЬНО МОЖЕТ (MAY) указывать длину полотна в мм (`leafLengthMm`) — необязательное числовое значение, не привязанное ни к какому конкретному `leaf_type` и не валидируемое по каталогу полотна; оно используется только для резолва ширины позиций, у чьего decorative_element_type есть диапазоны ширины (см. decorative-element-catalog, «Ширина сандрика по диапазону длины полотна»): для каждой такой позиции ширина в разбивке резолвится по этому значению, если оно попадает в один из диапазонов, иначе остаётся неопределённой. Отсутствие `leafLengthMm` не влияет на расчёт стоимости — только на то, резолвится ли ширина таких позиций в разбивке.

#### Scenario: Расчёт списка позиций декоративных элементов
- **WHEN** отправляется запрос с одной или несколькими позициями декоративных элементов (существующие decorative_element_type, с количеством или без)
- **THEN** эндпоинт возвращает итоговую розничную и дилерскую цену (сумма всех позиций) и разбивку по каждой позиции

#### Scenario: Пустой список позиций
- **WHEN** отправляется запрос с пустым списком позиций декоративных элементов (или без него)
- **THEN** эндпоинт отвечает кодом 200 с нулевой итоговой суммой и пустой разбивкой, без ошибки

#### Scenario: Количество по умолчанию равно 1
- **WHEN** позиция декоративного элемента в запросе не указывает количество
- **THEN** позиция учитывается с количеством 1

#### Scenario: Несуществующий тип декоративного элемента отклоняется
- **WHEN** позиция ссылается на несуществующий decorative_element_type
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Неположительное количество отклоняется
- **WHEN** позиция указывает количество ноль или отрицательное
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Одинаковые позиции не объединяются
- **WHEN** список содержит несколько позиций с одинаковым decorative_element_type
- **THEN** каждая учитывается как отдельная запись в разбивке, стоимости не объединяются

#### Scenario: Длина полотна резолвит ширину позиции с диапазонами
- **WHEN** запрос указывает `leafLengthMm` 700 и позицию с decorative_element_type «Сандрик Левия»
- **THEN** запись этой позиции в разбивке содержит ширину 1150 (диапазон ≤800)

#### Scenario: Без длины полотна ширина позиции с диапазонами не резолвится
- **WHEN** запрос не указывает `leafLengthMm` и содержит позицию с decorative_element_type «Сандрик Левия»
- **THEN** запись этой позиции в разбивке не содержит ширины; расчёт стоимости и остальные поля позиции не затронуты

#### Scenario: Длина полотна вне диапазонов не резолвит ширину
- **WHEN** запрос указывает `leafLengthMm`, не попадающее ни в один диапазон decorative_element_width_option позиции (например, 1500 для «Сандрик Левия»)
- **THEN** запись этой позиции в разбивке не содержит ширины, ошибки не возникает

#### Scenario: Длина полотна не влияет на позиции без диапазонов
- **WHEN** запрос указывает `leafLengthMm` и содержит позицию с decorative_element_type без строк decorative_element_width_option (например, «Плинтус Модо»)
- **THEN** ширина этой позиции в разбивке — собственный width_mm её типа, как и без указания `leafLengthMm`

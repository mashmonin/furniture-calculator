## ADDED Requirements

### Requirement: «Сандрик Левия», «Сандрик Арно» и «Сандрик Адела» доступны для коллекций «Элегант» и «Гармония»
Каталог ДОЛЖЕН (SHALL) содержать decorative_element_category «Сандрики» (`DEC-003`) и ровно три decorative_element_type в её составе — длина, толщина и цены у каждого фиксированы, ширина не задана напрямую (NULL) и определяется диапазоном (см. «Ширина сандрика по диапазону длины полотна»):

| Тип | length_mm | thickness_mm | dealer_price | retail_price |
|---|---|---|---|---|
| «Сандрик Левия» | 200 | 67 | 9574 | 16755 |
| «Сандрик Арно» | 188 | 64,5 | 6237 | 10915 |
| «Сандрик Адела» | 93 | 59 | 5237 | 9166 |

Для каждого из этих трёх типов ДОЛЖНА (SHALL) существовать строка decorative_element_option для каждого leaf_type, чья коллекция — «Элегант» (`LC-003`) или «Гармония» (`LC-004`), и НЕ ДОЛЖНО (SHALL NOT) существовать ни одной строки decorative_element_option, ссылающейся на leaf_type любой другой коллекции.

#### Scenario: Сандрики доступны для полотна «Элегант» и «Гармония»
- **WHEN** запрашивается список допустимых decorative_element_option для leaf_type коллекции «Элегант» или «Гармония»
- **THEN** в списке присутствуют все три типа — «Сандрик Левия», «Сандрик Арно» и «Сандрик Адела»

#### Scenario: Сандрики недоступны для полотна остальных коллекций
- **WHEN** запрашивается список допустимых decorative_element_option для leaf_type любой коллекции, кроме «Элегант» и «Гармония»
- **THEN** ни один из трёх типов категории «Сандрики» в списке не присутствует

### Requirement: Ширина сандрика по диапазону длины полотна
Decorative_element_type МОЖЕТ (MAY) вместо собственного фиксированного width_mm иметь одну или несколько строк decorative_element_width_option — каждая ссылается ровно на один decorative_element_type и задаёт диапазон длины полотна (min_value и/или max_value в мм; отсутствующая граница означает отсутствие ограничения с этой стороны) и ширину (width_mm), применимую в этом диапазоне. Диапазоны — включительные. У каждого из трёх типов сандриков ДОЛЖНО (SHALL) быть ровно три строки decorative_element_width_option со следующими значениями:

| Тип | Диапазон длины полотна, мм | width_mm |
|---|---|---|
| «Сандрик Левия» | ≤800 | 1150 |
| «Сандрик Левия» | 801–900 | 1250 |
| «Сандрик Левия» | 901–1200 | 1554 |
| «Сандрик Арно» | ≤800 | 1140 |
| «Сандрик Арно» | 801–900 | 1240 |
| «Сандрик Арно» | 901–1200 | 1554 |
| «Сандрик Адела» | ≤800 | 1110 |
| «Сандрик Адела» | 801–900 | 1240 |
| «Сандрик Адела» | 901–1200 | 1514 |

Для decorative_element_type, у которых нет ни одной строки decorative_element_width_option (плинтус, блок, база), эффективная ширина — их собственный width_mm, без изменений.

#### Scenario: У сандрика три диапазона ширины
- **WHEN** запрашиваются строки decorative_element_width_option для decorative_element_type «Сандрик Левия»
- **THEN** возвращаются ровно три строки с диапазонами ≤800, 801–900 и 901–1200 и шириной 1150, 1250 и 1554 соответственно

#### Scenario: Тип без диапазонов использует собственный width_mm
- **WHEN** запрашиваются строки decorative_element_width_option для decorative_element_type без диапазонов (например, «Плинтус Модо»)
- **THEN** список пуст, и эффективная ширина такого типа берётся из его собственного width_mm

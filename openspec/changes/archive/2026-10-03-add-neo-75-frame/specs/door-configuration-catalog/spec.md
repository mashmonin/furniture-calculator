## ADDED Requirements

### Requirement: Короб «NEO 75»
В справочнике frame_type ДОЛЖЕН (SHALL) существовать короб «NEO 75» (`FT-004`). Для него ДОЛЖНЫ (SHALL) существовать стандартные опции высоты: 2170 мм с диапазоном высоты полотна 2000–2000 и 2400 мм с диапазоном 2100–2300. Состав короба — две позиции frame_post для каждой высоты: «Стойка незарезная» (1 шт, без длины) и «Комплект зарезных стоек» (2 шт, длина равна высоте короба), с явными ценами (дилерская / розничная, руб.):

| Высота короба (высота полотна) | Стойка незарезная | Комплект зарезных стоек (2 шт) |
|---|---|---|
| 2170 (полотно 2000) | 1 404 / 2 317 | 2 808 / 4 633 |
| 2400 (полотно 2100, 2200, 2300) | 1 586 / 2 617 | 3 172 / 5 234 |

Никакие процентные наценки (наценки погонажа и иные наценки за высоту) к «NEO 75» НЕ ДОЛЖНЫ (SHALL NOT) применяться, и для него НЕ ДОЛЖНО (SHALL NOT) существовать ни одного правила pogonazh_surcharge_rule: стоимость короба равна сумме явных цен его позиций.

#### Scenario: Опции высоты и позиции короба
- **WHEN** запрашивается каталог для короба «NEO 75»
- **THEN** у него две опции высоты (2170 для полотна 2000, 2400 для полотна 2100–2300), и для каждой высоты по две позиции: незарезная стойка (1 шт) и комплект зарезных стоек (2 шт, длина 2170 или 2400)

#### Scenario: Цены короба для высоты 2170
- **WHEN** рассчитывается короб «NEO 75» для полотна высотой 2000
- **THEN** розничная цена короба равна 2 317 + 4 633 = 6 950, дилерская — 1 404 + 2 808 = 4 212

#### Scenario: Цены короба для высоты 2400
- **WHEN** рассчитывается короб «NEO 75» для полотна высотой 2100, 2200 или 2300
- **THEN** розничная цена короба равна 2 617 + 5 234 = 7 851, дилерская — 1 586 + 3 172 = 4 758

#### Scenario: У «NEO 75» нет процентных надбавок
- **WHEN** запрашиваются правила погонажа (pogonazh_surcharge_rule) для короба «NEO 75»
- **THEN** ни одного правила нет, и цена короба для обеих высот равна сумме цен позиций без каких-либо процентов

### Requirement: Конфигурации с коробом «NEO 75» для моделей «Эмаль Лайт»
Для каждой из моделей MONO MN 01, QUADRO QU 01, QUADRO QU 02, VENEZIA VN 01, VENEZIA VN 02 и REFLEX RF 01 ДОЛЖНА (SHALL) существовать door_configuration с коробом «NEO 75» без реверса (`is_reverse = false`), без четверти (`has_quarter = false`), без кромки, наличника и добора. Конфигурация «только полотно» этих моделей ДОЛЖНА (SHALL) сохраняться.

#### Scenario: Модель доступна с коробом «NEO 75»
- **WHEN** запрашивается каталог конфигураций для модели «Эмаль Лайт»
- **THEN** есть и конфигурация без короба, и конфигурация с коробом «NEO 75» без кромки, наличника и добора

#### Scenario: Короб «NEO 75» недоступен другим коллекциям
- **WHEN** запрашивается каталог конфигураций для моделей коллекций, не входящих в «Эмаль Лайт»
- **THEN** среди их конфигураций нет короба «NEO 75»

## ADDED Requirements

### Requirement: Привязка позиции короба к высоте
Frame_post МОЖЕТ (MAY) ссылаться на одну опцию высоты (liner_dimension_option оси «ВЫСОТА») того же frame_type. Позиция без привязки действует при любой высоте короба; позиция с привязкой учитывается только при выборе этой опции высоты. Комбинация frame_type, post_type и опции высоты (отсутствие привязки считается отдельным значением) ДОЛЖНА (SHALL) быть уникальной: для одного короба и типа позиции МОЖЕТ (MAY) существовать по одной записи на каждую опцию высоты и не более одной записи без привязки.

#### Scenario: Позиции одного типа для разных высот
- **WHEN** для одного frame_type и одного post_type вставляются две записи frame_post, привязанные к разным опциям высоты
- **THEN** обе записи сохраняются

#### Scenario: Повтор позиции для той же высоты отклоняется
- **WHEN** для frame_type, post_type и опции высоты уже существует запись frame_post, и вставляется вторая с теми же значениями
- **THEN** база данных отклоняет вставку

#### Scenario: Повтор позиции без привязки отклоняется
- **WHEN** для frame_type и post_type уже существует запись frame_post без привязки к высоте, и вставляется вторая без привязки
- **THEN** база данных отклоняет вставку

#### Scenario: Существующие короба не меняются
- **WHEN** запрашиваются записи frame_post коробов «ФАНТОМ», «КОМПЛАНАР» и «НЕО» после применения миграций
- **THEN** у них нет привязки к высоте, состав и цены прежние

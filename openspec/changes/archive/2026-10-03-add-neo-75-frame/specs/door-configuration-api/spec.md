## ADDED Requirements

### Requirement: Стоимость короба по позициям, подходящим к высоте
При расчёте стоимости frame-компонента система ДОЛЖНА (SHALL) учитывать только те записи frame_post, которые не привязаны к высоте либо привязаны к опции высоты, выбранной клиентом для этого короба. Короб «NEO 75» (`FT-004`) ДОЛЖЕН (SHALL) входить в набор коробов с диапазонным ограничением высоты (как «Компланар» и «НЕО»): высота короба определяется выбранной опцией, высота полотна должна лежать в её диапазоне, расчёт без выбранной высоты короба отклоняется. Для короба «NEO 75» никакие процентные наценки (погонажа и иные) НЕ ДОЛЖНЫ (SHALL NOT) применяться: базовая и итоговая цена короба равны. Каталог конфигураций ДОЛЖЕН (SHALL) отдавать для каждой позиции короба привязку к опции высоты (`heightOptionId`; null, если привязки нет).

#### Scenario: Короб «NEO 75» для полотна 2000
- **WHEN** отправляется запрос расчёта для модели «Эмаль Лайт» с коробом «NEO 75», высотой полотна 2000 и выбранной высотой короба 2170
- **THEN** стоимость короба — розница 6 950, дилер 4 212, без наценок

#### Scenario: Короб «NEO 75» для полотна 2200
- **WHEN** отправляется запрос расчёта для модели «Эмаль Лайт» с коробом «NEO 75», высотой полотна 2200 и выбранной высотой короба 2400
- **THEN** стоимость короба — розница 7 851, дилер 4 758, без наценок

#### Scenario: Цена короба «NEO 75» без надбавок
- **WHEN** рассчитывается короб «NEO 75» для любой из двух высот
- **THEN** базовая цена компонента (до наценок) равна его итоговой цене — процентные надбавки не применялись

#### Scenario: Высота полотна вне диапазона выбранной высоты короба
- **WHEN** выбрана высота короба 2170 для «NEO 75», а высота полотна равна 2200
- **THEN** эндпоинт отвечает ошибкой 400 и не выполняет расчёт

#### Scenario: Расчёт без высоты короба отклоняется
- **WHEN** отправляется запрос расчёта для конфигурации с коробом «NEO 75» без выбранной высоты короба
- **THEN** эндпоинт отвечает ошибкой 400

#### Scenario: Короба без привязки позиций к высоте считаются как прежде
- **WHEN** рассчитывается стоимость короба «НЕО» или «Компланар» (позиции без привязки к высоте)
- **THEN** стоимость равна сумме всех его позиций, как до этого изменения

#### Scenario: Каталог отдаёт привязку позиции к высоте
- **WHEN** запрашивается каталог конфигураций для модели с коробом «NEO 75»
- **THEN** у позиций короба в `posts` заполнен `heightOptionId` опции высоты, а у позиций короба «НЕО» он пуст

## Why

Для моделей «Эмаль Лайт» нужен короб «NEO 75»: сейчас они доступны только как «полотно без короба». Короб состоит из стойки незарезной (1 шт) и комплекта из двух стоек с фрезеровкой под петли, а его длина и цена зависят от высоты полотна. Это первый из компонентов, которые обещаны для «Эмаль Лайт» отдельным изменением (короб, наличники, добор, кромки).

## What Changes

- Новый тип короба `NEO 75` (`FT-004`).
- Состав короба — две позиции `frame_post`: «Стойка незарезная» (`PT-001`, 1 шт, без длины) и «Комплект зарезных стоек» (`PT-002`, 2 шт, длина = длине короба; это «стойки с фрезеровкой под петли» из прайса).
- Два класса высоты (в терминах проекта: «длина короба» — высота короба, «длина полотна» — высота полотна): высота полотна 2000 мм → короб 2170 мм; высота полотна 2100/2200/2300 мм → короб 2400 мм.
- Цены позиций по классам (дилер / розница, ₽):
  - короб 2170: стойка незарезная 1 404 / 2 317, комплект зарезных стоек 2 808 / 4 633;
  - короб 2400: стойка незарезная 1 586 / 2 617, комплект зарезных стоек 3 172 / 5 234.
  Цены явные: **никаких процентных надбавок** у «NEO 75» нет ни за высоту, ни за погонаж — стоимость короба равна сумме явных цен его позиций.
- **Изменение схемы:** у позиции короба `frame_post` появляется необязательная привязка к опции высоты короба (`height_option_id`); для короба стоимость складывается только из позиций, подходящих к выбранной высоте (или без привязки к высоте — как у существующих коробов). Уникальность позиции расширяется до (короб, тип позиции, высота).
- Для каждой из шести моделей «Эмаль Лайт» добавляется конфигурация с коробом «NEO 75» (без реверса, четверти, кромки, наличника и добора — они придут отдельными изменениями); существующая конфигурация «только полотно» остаётся как вариант «без короба».
- Короб «NEO 75» подчиняется тем же правилам диапазона высоты, что «НЕО»/«Компланар»: высота короба подбирается по высоте полотна, расчёт без высоты отклоняется.
- Frontend: каталог отдаёт привязку позиции к высоте; интерфейс использует существующий механизм подбора высоты короба по высоте полотна, а «Состав короба» показывает только две позиции выбранной высоты (а не все четыре); так же и в выгрузке спецификации.

### Modified Capabilities
- `frame-post-catalog`: привязка позиции короба к опции высоты, уникальность с учётом высоты.
- `door-configuration-catalog`: короб «NEO 75», его опции высоты и конфигурации моделей «Эмаль Лайт».
- `door-configurator-ui`: «Состав короба» показывает только позиции, подходящие к высоте короба (у «NEO 75» — пара «стойка незарезная ×1 + комплект зарезных стоек ×2» нужной длины).
- `door-configuration-api`: стоимость короба считается по позициям, подходящим к выбранной высоте; «NEO 75» входит в набор коробов с диапазоном высоты.

## Impact

- Backend: Liquibase (колонка и ограничение `frame_post`, `frame_type`, `liner_dimension_option`, `frame_post`, `door_configuration`), H2-override для ограничения, сущность `FramePost`, `FramePostDto`, `DoorConfigurationCatalogService`, `DoorConfigurationPricingService` (суммирование позиций и набор `HEIGHT_RANGE_FRAME_TYPE_CODES`).
- Frontend: тип `FramePostDto`, набор `HEIGHT_RANGE_FRAME_TYPE_CODES` в `ConfiguratorScreen.tsx`.
- Существующие короба (`ФАНТОМ`, `КОМПЛАНАР`, `НЕО`) и их цены не меняются.
- Вне scope: реверс/четверть, кромки, наличники, добор, цвета короба, «NEO 75» для других коллекций.

## ADDED Requirements

### Requirement: Прайс-лист «Фурнитура»
В справочнике price_list ДОЛЖНА (SHALL) существовать запись `PL-003` с name `prays_list_furnitura_tsfo_01_02_2026`. Все типы фурнитуры, заведённые из этого файла, ДОЛЖНЫ (SHALL) ссылаться на этот прайс-лист; полотна и коллекции на него не ссылаются.

#### Scenario: Запись прайс-листа существует
- **WHEN** запрашивается справочник price_list
- **THEN** в нём есть запись `PL-003` с name `prays_list_furnitura_tsfo_01_02_2026`

#### Scenario: Новая фурнитура связана с PL-003
- **WHEN** проверяется принадлежность типов фурнитуры из файла
- **THEN** каждый из них ссылается на price_list `PL-003`, а ранее существовавшая фурнитура — на `PL-001` или `PL-002`, как раньше

## Why

По новому Figma-макету (файл «Untitled», `node-id=0-1`) экран конфигуратора должен получить фирменную шапку и более наглядные подсказки о том, почему часть шагов (высота кромки, длина короба/наличника/добора) отфильтрована — сейчас эта фильтрация по высоте полотна происходит молча, без объяснения причины. Макет также уточняет цветовое оформление колонки результата расчёта (акцентная рамка, выделенный блок дилерской цены). Остальная часть макета — трёхколоночная раскладка, аккордеон разделов, карточки с Radio.Button/Select — уже реализована текущим приложением почти один в один (see change `redesign-configurator-layout`) и лишь донастраивается визуально.

## What Changes

- Добавить над трёхколоночной раскладкой фирменную шапку приложения (лого + название «Я-КОНФИГУРАТОР» + статичная подпись текущего прайс-листа), закреплённую сверху.
- Добавить рядом с карточками компонентов, чьи шаги высоты/длины фильтруются по высоте полотна (кромка, короб, наличник, добор), компактные подсказки-бейджи с текущим значением высоты полотна — по образцу макета («Высота полотна: …», «Длина погонажа: …», «для высоты полотна: …») — чтобы пользователю было видно, откуда взялось ограничение, даже если высота ещё не выбрана (бейдж в этом случае не показывается, как и сама фильтруемая группа).
- Уточнить цветовое оформление правой колонки результата расчёта под макет: акцентная рамка колонки и визуально выделенный блок дилерской цены (не просто список `Statistic`, а обособленный блок с фоном).
- Причесать положение и стиль иконки раскрытия/сворачивания в заголовках разделов аккордеона под макет (шеврон слева от заголовка).
- **Явно не входит в этот change** (обсуждено и отложено): второй пункт бокового меню «Фурнитура отдельно» (нужен отдельный экран поверх уже существующего API `leaf-standalone-pricing`) и кнопка «Скачать excel спецификацию» (нужен новый backend-эндпоинт экспорта). Оба — материал для отдельных change в будущем.
- Никаких изменений в REST API, доменной модели или БД — правки только во фронтенде (React/TSX/CSS), с использованием исключительно компонентов `antd`.

## Capabilities

### New Capabilities

(нет — изменение полностью укладывается в существующую капабилити `door-configurator-ui`)

### Modified Capabilities
- `door-configurator-ui`: добавляются требования на фирменную шапку приложения и на подсказки-бейджи высоты полотна рядом с компонентами, чьи шаги фильтруются по высоте полотна; уточняется визуальное оформление правой колонки результата (акцентная рамка, обособленный блок дилерской цены) в дополнение к уже описанной трёхколоночной раскладке.

## Impact

- **Frontend**: `frontend/src/App.tsx` (новый блок шапки, бейджи-подсказки на карточках «Кромка», «Короб», «Наличник», «Добор», доработка блока результата расчёта), `frontend/src/App.css`/`index.css` (стили шапки, бейджей, акцентной рамки и блока дилерской цены). Новых npm-зависимостей не требуется — используются существующие компоненты `antd` (`Layout`/`Flex`, `Tag` или аналог для бейджей, уже используемые `Card`/`Statistic`/`Collapse`).
- **Backend**: без изменений.
- **REST API**: без изменений — все данные для бейджей (текущая высота полотна) уже есть в состоянии фронтенда.

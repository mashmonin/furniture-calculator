## MODIFIED Requirements

### Requirement: Каталог фурнитуры из файла
Экран сервиса ДОЛЖЕН (SHALL) показывать каталог фурнитуры прайс-листа `prays_list_furnitura_tsfo_01_02_2026` (`PL-003`) под лентой дверей. Вверху каталога — фильтры: бренд (выпадающий список: HAUSDOORS, Fantom, Vantage — по умолчанию выбран первый), «Элемент» (выпадающий список разделов выбранного бренда, названия без префикса бренда), «Цвет» (выпадающий список цветов выбранного бренда и элемента, рядом с «Элемент») и текстовый поиск по модели, цвету и артикулу. Ниже — блок «Модель» со списком записей на всю ширину экрана: ОДНА запись = модель выбранного бренда + ОДИН цвет + одна розничная цена за единицу (цена дилера НЕ ДОЛЖНА (SHALL NOT) показываться); в строке записи — название модели, цвет, цена розница и кнопка «+»; все элементы строки, включая кнопку «+», ДОЛЖНЫ (SHALL) помещаться в границах списка (цвет при нехватке ширины сужается). Название раздела под названием модели НЕ ДОЛЖНО (SHALL NOT) выводиться. Запись выбирается нажатием на строку (подсвечивается), кнопка «+» в строке добавляет эту запись к выбранной двери. Отдельных списков «Цвет» и блока «Выбранная модель» нет. Смена бренда сбрасывает фильтры «Элемент» и «Цвет», смена элемента — фильтр «Цвет». Фурнитура других прайс-листов в этом каталоге НЕ ДОЛЖНА (SHALL NOT) показываться.

#### Scenario: Выбор начинается с бренда
- **WHEN** пользователь открывает сервис «Фурнитура»
- **THEN** выбран первый бренд каталога, в списке записей — только записи его моделей

#### Scenario: Одна запись — один цвет и одна цена
- **WHEN** у модели «Дверная ручка Fantom "Кассандра"» четыре цвета
- **THEN** в списке четыре отдельные записи, в каждой — один цвет и одна цена розницы

#### Scenario: Фильтр «Элемент»
- **WHEN** пользователь выбирает элемент «Фиксаторы»
- **THEN** в списке остаются только записи этого элемента выбранного бренда

#### Scenario: Фильтр «Цвет»
- **WHEN** пользователь выбирает цвет «Матовый черный»
- **THEN** в списке остаются только записи этого цвета выбранного бренда и элемента

#### Scenario: Поиск
- **WHEN** пользователь вводит артикул, цвет или часть названия модели
- **THEN** в списке остаются только записи выбранного бренда, у которых совпадает название модели, цвет или артикул

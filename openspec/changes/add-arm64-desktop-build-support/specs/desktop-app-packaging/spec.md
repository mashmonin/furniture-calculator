## MODIFIED Requirements

### Requirement: Автономная установка без внешних зависимостей
Система SHALL распространяться как установщик macOS (`.dmg`) под архитектуру процессора конечного пользователя (Intel x86_64 или Apple Silicon arm64), после установки которого приложение запускается без необходимости отдельно устанавливать Java Runtime или сервер базы данных. Установщики под разные архитектуры SHALL иметь различимые имена файлов, чтобы пользователь мог однозначно выбрать подходящий для своей машины.

#### Scenario: Запуск на чистой машине
- **WHEN** пользователь без установленной Java и без запущенного сервера БД устанавливает и запускает приложение
- **THEN** приложение успешно запускается и становится пригодным для работы

#### Scenario: Выбор установщика под архитектуру Mac
- **WHEN** пользователь собирается установить приложение на Mac с определённой архитектурой процессора (Intel или Apple Silicon)
- **THEN** доступен установщик, чьё имя файла явно указывает на эту архитектуру, и после установки приложение работает нативно (без эмуляции) на этой архитектуре

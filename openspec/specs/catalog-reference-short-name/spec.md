## Purpose

Определяет необязательное «краткое наименование» для справочных типов, реализующих общий контракт `CatalogType` (edge_type, door_casing_type, frame_extensions_type, post_type, frame_type, hardware_category, hardware_type, liner_dimension_type, colour_type, leaf_type, leaf_collection), и то, как оно отдаётся на фронт вместе с id/code/name.

## Requirements

### Requirement: Краткое наименование справочного типа
Каждая справочная строка, реализующая `CatalogType` (edge_type, door_casing_type, frame_extensions_type, post_type, frame_type, hardware_category, hardware_type, liner_dimension_type, colour_type, leaf_type, leaf_collection), МОЖЕТ (MAY) иметь краткое наименование (short_name) — необязательное человекочитаемое имя, короче основного name, предназначенное для компактных мест интерфейса. Отсутствие краткого наименования не является ошибкой и не влияет на обязательность и значение name.

#### Scenario: Краткое наименование не задано
- **WHEN** справочная строка (например, edge_type) вставляется без short_name
- **THEN** строка сохраняется успешно, name остаётся обязательным и без изменений

#### Scenario: Краткое наименование задано
- **WHEN** справочной строке присвоено краткое наименование
- **THEN** строка сохраняется с этим значением short_name, не затрагивая её name и code

### Requirement: Краткое наименование в ответе каталога
Всюду, где справочный тип, реализующий `CatalogType`, отдаётся на фронт (в частности, через `ReferenceDto`: id, code, name), ответ ДОЛЖЕН (SHALL) дополнительно содержать краткое наименование (shortName) этой строки — значение short_name, если оно задано, иначе `null`. Существующие поля (id, code, name) не меняются.

#### Scenario: Краткое наименование присутствует в ответе
- **WHEN** запрашивается любой ответ API, содержащий справочный тип с заданным short_name (например, edge_type в каталоге конфигураций)
- **THEN** в ответе для этой строки shortName равен её short_name, а id, code и name возвращаются как прежде

#### Scenario: Краткое наименование отсутствует в ответе
- **WHEN** запрашивается ответ API для справочной строки, у которой short_name не задан
- **THEN** в ответе для этой строки shortName равен `null`, а id, code и name возвращаются как прежде

### Requirement: Краткие наименования кромок
Для строк edge_type со следующими name ДОЛЖНО (SHALL) быть задано указанное краткое наименование:
- «ПРЯМАЯ КРОМКА ПО ПЕРИМЕТРУ ПОЛОТНА» → «Прямая»
- «КРОМКА ДЛЯ ПОЛОТНА С ЧЕТВЕРТЬЮ ПО ПЕРИМЕТРУ» → «С четвертью»

Для остальных строк edge_type краткое наименование не задаётся этим изменением.

#### Scenario: Краткие наименования кромок возвращаются в каталоге
- **WHEN** запрашивается каталог конфигураций или иной ответ API, включающий edge_type «ПРЯМАЯ КРОМКА ПО ПЕРИМЕТРУ ПОЛОТНА» или «КРОМКА ДЛЯ ПОЛОТНА С ЧЕТВЕРТЬЮ ПО ПЕРИМЕТРУ»
- **THEN** для первой в ответе shortName равен «Прямая», для второй — «С четвертью»

# Я-Конфигуратор (Furniture Calculator)

Приложение для подбора и расчёта стоимости межкомнатных дверей и комплектующих: от выбора коллекции и размеров до готовой спецификации и коммерческого предложения.

Пошагово собираете конфигурацию, а цена пересчитывается на лету. Результат уходит в корзину заказа, из неё выгружается в Excel или PDF.

## Возможности

- **Каскадный подбор двери**: обратное открывание → тип полотна → коллекция → модель → размеры и цвет → кромка → короб → наличник и добор → декоративные элементы.
- **Расчёт цены без кнопки «Рассчитать»**: розничная цена, разбивка по компонентам и надбавки (нестандартные размеры, двусторонняя покраска, цвета RAL/NCS, погонаж).
- **Каталог фурнитуры** с категориями, брендами и артикулами. Фурнитуру можно добавить к уже собранным дверям.
- **Корзина заказа** с редактированием позиций и количества.
- **Экспорт**: Excel-спецификация и клиентское коммерческое предложение в PDF.
- **Несколько прайс-листов**: у каждой коллекции и позиции фурнитуры отображается источник цены.
- **Десктоп-версия для macOS** (`.dmg`, Apple Silicon и Intel). Java и СУБД ставить не нужно, внутри встроенная H2.
- **Проверка обновлений** с уведомлением о новой версии.

Готовые сборки лежат на странице [Releases](https://github.com/mashmonin/furniture-calculator/releases).

## Стек

| Слой | Технологии |
|---|---|
| Backend | Java 21, Spring Boot 4.1, Spring Data JPA, Liquibase, Apache POI, OpenPDF |
| Frontend | React 19, TypeScript, Vite, Ant Design |
| База данных | PostgreSQL (сервер) / H2 (десктоп), схема только через Liquibase |
| Десктоп | JavaFX-оболочка над тем же Spring Boot приложением |

Архитектура: слоистая (controller / service / repository), REST API только с JSON. Миграции БД не содержат триггеров и процедур, поэтому одинаково работают на PostgreSQL и H2.

## Быстрый старт

Нужны JDK 21, Node.js и Docker.

```bash
# 1. База данных (PostgreSQL на localhost:5434)
docker compose up -d

# 2. Backend
cd backend
./gradlew bootRun

# 3. Frontend (в другом терминале)
cd frontend
npm install
npm run dev
```

Другие команды:

```bash
./gradlew test        # тесты backend (из backend/)
npm run build         # прод-сборка frontend (из frontend/)
npm run lint          # линт frontend
```

## Структура репозитория

```
backend/    Spring Boot API (Gradle wrapper внутри)
frontend/   Vite + React + TypeScript
openspec/   Спецификации и история изменений
```

## Разработка по спецификациям

Проект ведётся по spec-driven подходу с [OpenSpec](https://github.com/Fission-AI/OpenSpec). Нетривиальные изменения сначала оформляются как proposal, затем реализуются и архивируются. Актуальное поведение системы описано в [`openspec/specs/`](openspec/specs/): каталог конфигураций, правила надбавок, корзина, экспорт, упаковка десктопа и другие области.
